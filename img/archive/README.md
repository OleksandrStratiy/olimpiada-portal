# Зображення до умов задач

Поклади сюди малюнки з оригінальних документів. Поки файла немає, на сторінці задачі
показується заглушка з його назвою. Назва файла має збігатися точно.

| Файл | Задача | Що на малюнку |
| --- | --- | --- |
| `pattern2024-ideal.png` | Pattern2024 (2024–2025) | Приклади ідеальних візерунків для таблиці 2х3 |
| `pattern2024-not-ideal.png` | Pattern2024 (2024–2025) | Приклади неідеальних візерунків для таблиці 2х3 |
| `king2021.png` | King2021 (2021–2022) | Можливі ходи короля |
| `table2021.png` | Table2021 (2021–2022) | Ілюстрація до прикладу |
| `learning2021.png` | learning (2021–2022) | Ілюстрація до задачі |
| `toxins2021.png` | Toxins (2021–2022) | Приклад безпечного маршруту |
| `hotel2018.png` | Hotel (2018–2019) | Ділянка компанії: берег і море |

Щоб додати малюнок до іншої задачі, напиши в її умові окремим абзацом
`[[img:назва-файла.png|Підпис під малюнком]]` і поклади файл у цю папку.
Підходять PNG, JPG, SVG або WebP; бажана ширина до 1000 px.
