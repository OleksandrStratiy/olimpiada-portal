# Зошит олімпіадника

Сайт для навчання програмування мовою C++ з нуля і підготовки до олімпіади з інформатики.
Сайт статичний — працює без сервера й бази даних, тож його можна безкоштовно розмістити на GitHub Pages.

## Що є на сайті

- **Курс** — 39 уроків у 8 розділах: від першої програми до олімпіадних алгоритмів.
  Кожен урок пояснює одну тему простими словами і містить:
  приклади коду, які можна змінювати й запускати просто на сторінці;
  виноски з порадами і типовими помилками; тест «Перевір себе» з поясненнями;
  задачі з автоматичною перевіркою, підказками і розв’язками.
- **Задачі** — тренувальні задачі й завдання олімпіад, з фільтрами за темою (уроком), рівнем і станом.
  Кожна задача прив’язана до уроку, після якого її вже можна розв’язати.
- **Олімпіади** — завдання ІІ (районного) етапу Всеукраїнської олімпіади у Вінницькій області
  з 2013–2014 по 2024–2025 н. р. в оригінальному вигляді, з документами для завантаження.
- **Прогрес** — пройдені уроки й розв’язані задачі. Прогрес зберігається в браузері учня;
  його можна зберегти у файл і відновити на іншому комп’ютері.
- **Для вчителя** — додавання й редагування задач (PIN за замовчуванням `1234`).

### Розділи курсу

1. Знайомство з C++ — що таке програма, де писати код, перша програма, виведення.
2. Змінні та обчислення — змінні, введення, арифметика й ділення націло, типи даних, математичні функції.
3. Розгалуження — `if`, складні умови, `else if` і `switch`.
4. Цикли — `for`, `while`, типові задачі з циклами, `break`/`continue` і дільники, вкладені цикли.
5. Масиви та рядки — `vector`, алгоритми з масивами, двовимірні масиви, символи, рядки.
6. Функції — функції, параметри-посилання, рекурсія.
7. Стандартна бібліотека — сортування, `pair` і `struct`, `set` і `map`, стек і черга.
8. Олімпіадні алгоритми — як розв’язувати олімпіадні задачі, складність, теорія чисел, префіксні суми,
   два вказівники, бінарний пошук, жадібні алгоритми, повний перебір, динамічне програмування, графи.

## Як працює запуск коду

Кнопки «Запустити» і «Перевірити» надсилають код до відкритого онлайн-компілятора
[Compiler Explorer](https://godbolt.org) (компілятор GCC, стандарт C++17). Нічого встановлювати не потрібно,
але потрібен інтернет. Якщо в школі сайт godbolt.org заблоковано, код можна скопіювати
в Code::Blocks чи інше середовище. Компілятор і параметри задаються в `js/config.js`.

Перевірка задачі запускає програму учня на прикладах і додаткових тестах і порівнює відповіді так,
як це роблять перевіряльні системи олімпіад: за словами, без урахування зайвих пробілів.

## Як запустити на своєму комп’ютері

Сайт читає файли курсу й задач, а браузер не дозволяє цього, якщо відкрити `index.html`
подвійним кліком. Тому потрібен простий локальний сервер. У папці проєкту виконай

```bash
python -m http.server 8000
```

і відкрий у браузері <http://localhost:8000>.

## Як розмістити на GitHub Pages

1. У репозиторії відкрий **Settings → Pages**.
2. У полі **Source** вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`.
3. За хвилину-дві сайт буде доступний за адресою `https://<логін>.github.io/<назва-репозиторію>/`.

Файл `.nojekyll` у корені обов’язковий: без нього GitHub Pages обробляє файли Markdown
і уроки не завантажаться.

Щоб показати сайт на шкільному сайті, дай на нього посилання в меню або вбудуй через `<iframe>`.

## Як редагувати уроки

Кожен урок — це файл `lessons/<id>.md`, а список і порядок уроків — у `data/course.json`.
Файли можна редагувати прямо на GitHub: відкрий файл і натисни олівець. Перевір себе командою
`python tools/check.py <id>` (див. нижче) — вона скомпілює всі програми уроку.

Урок пишеться звичайним Markdown: `## Заголовок`, абзаци, списки, таблиці, `**жирний**`, `*курсив*`,
`` `код` ``, `[посилання](адреса)`, `![підпис](шлях-до-малюнка)`. Перший рядок — `# Назва уроку`.
Посилання на інший урок: `[урок про цикли](#/lesson/for)`. Окрім цього, є кілька додатків.

### Виноски

```markdown
> [!TIP]
> Текст поради.
```

Види: `NOTE` (Зверни увагу), `TIP` (Порада), `IMPORTANT` (Запам’ятай), `WARNING` (Обережно),
`CAUTION` (Типова помилка). Власний заголовок пишуть після позначки: `> [!NOTE] У цьому уроці`.

### Програми з введенням і виведенням

Блок ` ```cpp ` з повною програмою (з `main`) отримує кнопки «Змінити» і «Запустити».
Якщо одразу після нього йдуть блоки ` ```input ` і/або ` ```output `, вони показуються під кодом
як приклад, а `tools/check.py` перевіряє, що програма справді виводить саме це.

````markdown
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    return 0;
}
```

```input
2 3
```

```output
5
```
````

Позначки після `cpp`: ` ```cpp error ` — код навмисно з помилкою (перевірка переконується, що він
не компілюється); ` ```cpp norun ` — без кнопки «Запустити» (наприклад, нескінченний цикл).

### Тест «Перевір себе»

````markdown
```quiz
? Що виведе фрагмент?
| int x = 4;
| cout << x * 2;
- 4
+ 8
- x * 2
: Пояснення, яке з’явиться після правильної відповіді.
```
````

`?` — питання, `|` — рядки коду до питання, `+` — правильний варіант (рівно один),
`-` — неправильний, `:` — пояснення. Питання розділяють порожнім рядком.

### Задача з перевіркою

````markdown
```exercise
id: sum
title: Сума двох чисел
level: 1
=== statement
Дано два цілих числа. Виведи їхню суму.
=== input
Два цілих числа `a` і `b` (−1000 ≤ a, b ≤ 1000).
=== output
Одне число — сума.
=== example
2 3
---
5
=== test
-1000 -1000
---
-2000
=== hint
Прочитай обидва числа однією командою `cin`.
=== solution
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    return 0;
}
```
````

- `id` — латинськими літерами, унікальний у межах уроку (від нього залежить збережений прогрес — не змінюй його без потреби);
- `level` — 1 (легка), 2 (середня), 3 (складна);
- `example` — приклад, який бачить учень; `test` — додатковий тест, який використовується лише при перевірці;
  у прикладах і тестах введення відділяється від виведення рядком `---`;
- `hint` може бути кілька — учень відкриває їх по одній;
- `starter` — необов’язковий початковий код у редакторі; якщо він навмисно з помилками, додай рядок `broken: true`;
- `note` — необов’язковий текст після прикладів.

Якщо в умові задачі потрібен блок коду з ` ``` `, огорни всю задачу чотирма зворотними лапками: ` ````exercise `.

### Як додати новий урок

1. Створи файл `lessons/<id>.md`.
2. Додай урок у потрібний розділ `data/course.json`: `{ "id": "<id>", "title": "…", "summary": "…", "minutes": 20 }`.
3. Запусти `python tools/check.py <id>`.

## Як додати або змінити задачі

**Через сайт.** Відкрий «Для вчителя», додай чи відредагуй задачі й натисни «archive.json» або «problems.json».
Заміни отриманим файлом однойменний файл у папці `data/` і зроби коміт.

**Вручну.** Відредагуй файли в `data/`. Поле `topic` задачі — це `id` уроку, після якого задачу
вже можна розв’язати (наприклад, `"for"`, `"binary-search"`), або `"other"`. Олімпіадна задача виглядає так:

```json
{
  "id": "Racing2024",
  "title": "Автомобіль",
  "year": "2024-25",
  "groups": ["8 клас і молодші", "9–11 класи"],
  "topic": "math",
  "level": 1,
  "statement": "Текст умови після слів «Задача Racing2024.»",
  "techLabel": "Технічні умови.",
  "tech": "Програма **Racing2024** читає з пристрою стандартного введення …",
  "examples": [{ "in": "1 3 4 5 7", "out": "3" }],
  "note": "Примітка упорядника (необов’язково)",
  "hints": [],
  "solution": "",
  "link": ""
}
```

У текстах задач: порожній рядок — новий абзац, `` `код` ``, `**жирний**`.
Малюнок — окремим абзацом `[[img:файл.png|Підпис]]`, файл кладеться в `img/archive/`.

### Новий рік олімпіади

1. Поклади документи із завданнями в `documents/`, наприклад `2025-26_8.pdf` і `2025-26_9-11.pdf`.
2. Додай рік у `data/years.json` (за зразком наявних років).
3. Додай задачі з `"year": "2025-26"` і тими самими назвами груп — через сайт або в `archive.json`.

## Перевірка

```bash
python tools/check.py                 # усе: уроки, задачі, розв’язки
python tools/check.py hello for       # лише вказані уроки
python tools/check.py --no-compile    # лише структура, без компіляції
```

Скрипт перевіряє структуру курсу і JSON-файлів, компілює кожну програму з уроків (потрібен `g++`),
звіряє її виведення з блоками `output`, перевіряє тести «Перевір себе» і проганяє розв’язки задач
на прикладах і тестах. Ту саму перевірку автоматично виконує GitHub Actions після кожної зміни
в `lessons/`, `data/` чи `tools/`.

## Джерела завдань

Завдання ІІ етапу Всеукраїнської олімпіади з інформатики у Вінницькій області
(Департамент освіти і науки Вінницької ОДА, Вінницька академія неперервної освіти).
Права на тексти завдань належать їхнім авторам. Примітки упорядника позначено окремо
від оригінальних умов.
