# Зошит олімпіадника

Портал для підготовки учнів до олімпіади з інформатики (мова C++): тренувальні задачі,
завдання ІІ (районного) етапу Всеукраїнської олімпіади у Вінницькій області за минулі роки
і довідник з теорії. Сайт статичний — працює без сервера й бази даних, тож його можна
безкоштовно розмістити на GitHub Pages.

## Що є на сайті

- **Задачі** — тренувальні задачі з умовою, прикладами, підказками й розв’язком на C++.
- **Минулі олімпіади** — завдання районних олімпіад з 2013–2014 по 2024–2025 н. р.
  Умови наведено так, як в оригінальних документах, а самі документи можна завантажити.
- **Теорія** — 14 тем від першої програми до графів, з кодом і типовими помилками.
- **Мій прогрес** — учень позначає задачі як «Розв’язую» або «Розв’язано».
  Позначки зберігаються в браузері учня.
- **Для вчителя** — редагування задач і вивантаження оновлених файлів даних.

## Структура проєкту

```
├── index.html              сторінка порталу
├── css/style.css           стилі
├── js/
│   ├── main.js             запуск, маршрути, обробка подій
│   ├── state.js            завантаження даних, прогрес, чернетки вчителя
│   ├── config.js           налаштування (PIN учителя)
│   ├── utils.js            допоміжні функції, розмітка тексту, малюнки
│   ├── highlight.js        підсвічування коду C++
│   └── views/              сторінки: home, problem, archive, theory, progress, teacher
├── data/
│   ├── problems.json       тренувальні задачі
│   ├── archive.json        задачі олімпіад минулих років
│   ├── years.json          роки олімпіад і оригінальні документи до них
│   └── theory.json         довідник з теорії
├── documents/              оригінальні документи із завданнями (PDF, DOCX)
├── img/archive/            малюнки до умов задач (див. README у цій папці)
└── tools/check_data.py     перевірка даних і розв’язків
```

## Як запустити на своєму комп’ютері

Сайт читає дані з файлів JSON, а браузер не дозволяє цього, якщо відкрити `index.html`
подвійним кліком. Тому потрібен простий локальний сервер. У папці проєкту виконай:

```bash
python -m http.server 8000
```

і відкрий у браузері <http://localhost:8000>.

## Як розмістити на GitHub Pages

1. Створи репозиторій на GitHub і завантаж туди вміст цієї папки.
2. У репозиторії відкрий **Settings → Pages**.
3. У полі **Source** вибери **Deploy from a branch**, гілку `main` і папку `/ (root)`.
4. За хвилину-дві сайт буде доступний за адресою `https://<логін>.github.io/<назва-репозиторію>/`.

Щоб показати портал на шкільному сайті WordPress, дай на нього посилання в меню
або вбудуй через `<iframe>`.

## Як додати або змінити задачі

**Через сайт.** Відкрий розділ «Для вчителя» (PIN за замовчуванням `1234`, змінюється
в `js/config.js`), додай чи відредагуй задачі й натисни «Завантажити archive.json»
або «Завантажити problems.json». Заміни отриманим файлом однойменний файл у папці `data/`
і зроби коміт.

**Вручну.** Відредагуй файли в `data/` у будь-якому редакторі. Олімпіадна задача виглядає так:

```json
{
  "id": "Racing2024",
  "title": "Автомобіль",
  "year": "2024-25",
  "groups": ["8 клас і молодші", "9–11 класи"],
  "topic": "start",
  "level": 1,
  "statement": "Текст умови після слів «Задача Racing2024.»",
  "techLabel": "Технічні умови.",
  "tech": "Програма **Racing2024** читає з пристрою стандартного введення …",
  "examples": [{ "in": "1 3 4 5 7", "out": "3" }],
  "note": "Примітка упорядника (необов’язково)",
  "hints": [],
  "solution": "",
  "link": ""
}
```

- `id` — назва задачі (програми) так, як у документі; має бути унікальною.
- `topic` — тема з `theory.json` (`start`, `types`, `dp`, `graphs` …) або `other`.
- `level` — 1 (розминка), 2 (середній), 3 (складний).
- У тексті: порожній рядок — новий абзац, `` `код` ``, `**жирний**`.
- Малюнок — окремим абзацом `[[img:файл.png|Підпис]]`, файл кладеться в `img/archive/`.
  Поки файла немає, на сайті видно заглушку.

## Як додати новий рік олімпіади

1. Поклади документи із завданнями в `documents/`, наприклад `2025-26_8.pdf` і `2025-26_9-11.pdf`.
2. Додай рік у `data/years.json`:

```json
{
  "id": "2025-26",
  "title": "2025–2026 н. р.",
  "docs": [
    { "group": "8 клас і молодші", "file": "documents/2025-26_8.pdf", "heading": "Завдання для учнів 8 класів та молодших", "info": "" },
    { "group": "9–11 класи", "file": "documents/2025-26_9-11.pdf", "heading": "Завдання для учнів 9-11 класів", "info": "" }
  ]
}
```

3. Додай задачі з `"year": "2025-26"` і тими самими назвами груп — через сайт або в `archive.json`.

## Перевірка даних

```bash
python tools/check_data.py
```

Скрипт перевіряє структуру JSON-файлів, наявність документів і компілює кожен розв’язок
на C++ (потрібен `g++`), запускаючи його на прикладах з умови. Ту саму перевірку
автоматично виконує GitHub Actions після кожного коміту в `data/`.

## Джерела завдань

Завдання ІІ етапу Всеукраїнської олімпіади з інформатики у Вінницькій області
(Департамент освіти і науки Вінницької ОДА, Вінницька академія неперервної освіти).
Права на тексти завдань належать їхнім авторам. Примітки упорядника позначено окремо
від оригінальних умов.
