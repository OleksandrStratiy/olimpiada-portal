# Змінні

Програми рідко працюють з наперед відомими числами. Зазвичай вони щось запам’ятовують, змінюють і використовують знову. Для цього існують **змінні**.

> [!NOTE] У цьому уроці
> - що таке змінна, як її оголосити і присвоїти їй значення;
> - як змінюється значення змінної і що означає `x = x + 1`;
> - короткі записи `+=`, `-=`, `++`;
> - як назвати змінну;
> - як поміняти значення двох змінних місцями.

## Змінна — це комірка з ім’ям

Уяви коробку з наліпкою. На наліпці написано ім’я, наприклад `age`, а всередині лежить значення — число 13. Коробка може зберігати лише одне значення: якщо покласти нове, старе зникне.

У пам’яті комп’ютера змінна — це така сама комірка. Щоб нею користуватися, її треба **оголосити** — вказати тип і ім’я:

```cpp
int age;
```

`int` (від *integer* — «ціле число») — це **тип**: у змінній `age` зберігатимуться цілі числа. Про інші типи поговоримо в окремому уроці.

Покласти значення в змінну — означає **присвоїти** його:

```cpp
age = 13;
```

Оголосити змінну і одразу дати їй значення можна одним рядком:

```cpp
int age = 13;
```

Щоб скористатися значенням, просто пиши ім’я змінної — **без лапок**:

```cpp
#include <iostream>
using namespace std;

int main() {
    int age = 13;
    cout << age << "\n";
    cout << "age" << "\n";
    cout << age + 1 << "\n";
    return 0;
}
```

```output
13
age
14
```

Ім’я без лапок — це змінна, і виводиться її значення. Ім’я в лапках — просто текст.

## Кілька змінних

Кілька змінних одного типу можна оголосити в одному рядку через кому:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 7, b = 3;
    int sum = a + b;
    int product = a * b;
    cout << sum << " " << product << "\n";
    return 0;
}
```

```output
10 21
```

## Знак `=` — це не «дорівнює»

У математиці запис `x = x + 1` — нісенітниця: число не може дорівнювати собі плюс один. А в програмуванні `=` означає **«обчисли праву частину і поклади результат у змінну ліворуч»**. Тому `x = x + 1` читається так: «візьми значення `x`, додай 1 і запиши результат назад у `x`». Тобто збільш `x` на 1.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5;
    cout << x << "\n";
    x = x + 1;
    cout << x << "\n";
    x = x * 10;
    cout << x << "\n";
    return 0;
}
```

```output
5
6
60
```

### Таблиця значень

Щоб розібратися, що робить програма, корисно виконати її «на папері» — записувати значення змінних після кожного рядка. Таку таблицю називають **трасуванням**:

```cpp
int x = 5;
int y = x * 2;
x = x + y;
y = y - 1;
x = x / 3;
```

| Рядок | x | y |
| --- | --- | --- |
| `int x = 5;` | 5 | — |
| `int y = x * 2;` | 5 | 10 |
| `x = x + y;` | 15 | 10 |
| `y = y - 1;` | 15 | 9 |
| `x = x / 3;` | 5 | 9 |

> [!IMPORTANT]
> Змінна пам’ятає лише **останнє** присвоєне значення. А вираз обчислюється в той момент, коли виконується рядок: якщо потім змінити `x`, змінна `y`, обчислена раніше через `x`, сама не зміниться.

## Короткі записи

Змінювати змінну «саму через себе» доводиться так часто, що для цього є короткі записи:

| Короткий запис | Те саме, що | Що робить |
| --- | --- | --- |
| `x += 5;` | `x = x + 5;` | збільшує на 5 |
| `x -= 5;` | `x = x - 5;` | зменшує на 5 |
| `x *= 2;` | `x = x * 2;` | множить на 2 |
| `x /= 2;` | `x = x / 2;` | ділить на 2 |
| `x++;` | `x = x + 1;` | збільшує на 1 |
| `x--;` | `x = x - 1;` | зменшує на 1 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int coins = 10;
    coins += 5;
    coins *= 2;
    coins--;
    cout << coins << "\n";
    return 0;
}
```

```output
29
```

Порахуй сам: 10 → 15 → 30 → 29.

## Як назвати змінну

Правила для імен:

- можна використовувати латинські літери, цифри і знак підкреслення `_`;
- ім’я **не може** починатися з цифри;
- пробіли в імені не можна;
- великі й малі літери різняться: `sum` і `Sum` — дві різні змінні;
- не можна брати слова, які вже щось означають у C++: `int`, `return`, `main` тощо.

| Ім’я | Чи можна |
| --- | --- |
| `sum`, `count`, `max_value`, `x1` | так |
| `2x` | ні: починається з цифри |
| `my sum` | ні: пробіл |
| `int` | ні: службове слово |
| `ціна` | ні: українські літери |

> [!TIP]
> Давай змінним зрозумілі імена: `sum`, `count`, `price` значно зрозуміліші за `a`, `b`, `c`. Короткі імена на кшталт `n`, `x`, `i` годяться, коли зміст очевидний (наприклад, `n` — кількість чисел у задачі).

## Важливі правила

**Змінну оголошують один раз.** Повторне оголошення — помилка:

```cpp error
#include <iostream>
using namespace std;

int main() {
    int x = 5;
    int x = 7;
    cout << x << "\n";
    return 0;
}
```

Щоб змінити значення, тип не пишуть: `x = 7;`.

**Змінну спершу оголошують, а потім використовують.** Якщо написати `y = 3;` раніше, ніж `int y;`, компілятор повідомить `'y' was not declared in this scope`.

**Не читай змінну, якій нічого не присвоєно.** У щойно оголошеній змінній (`int x;`) може лежати будь-яке «сміття», що залишилося в пам’яті. Тому або одразу задавай початкове значення, або присвоюй його перед першим використанням.

## Обмін значень двох змінних

Класична задача: у змінній `a` лежить 3, у `b` — 8. Треба поміняти значення місцями. Наївна спроба не працює:

```cpp
a = b;   // a = 8, b = 8
b = a;   // b = 8 — значення 3 вже втрачено!
```

Розв’язок — як із двома склянками соку: щоб поміняти напої, потрібна третя, порожня склянка. Збережемо одне значення в допоміжній змінній:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 8;
    int temp = a;   // temp = 3
    a = b;          // a = 8
    b = temp;       // b = 3
    cout << a << " " << b << "\n";
    return 0;
}
```

```output
8 3
```

## Перевір себе

```quiz
? Що виведе фрагмент?
| int x = 4;
| x = x * 3;
| cout << x;
- 4
+ 12
- x * 3
: Спершу обчислюється 4 · 3 = 12, і результат записується назад у `x`.

? Що виведе фрагмент?
| int a = 2;
| int b = a + 3;
| a = 10;
| cout << b;
+ 5
- 13
- 10
: `b` обчислили, коли `a` дорівнювало 2. Подальша зміна `a` на `b` не впливає.

? Яке ім’я змінної правильне?
- `2nd_place`
- `total sum`
+ `total_sum`
- `return`
: Ім’я не може починатися з цифри, містити пробіл чи бути службовим словом.

? Що робить команда `score += 10;`?
- Присвоює змінній `score` значення 10
+ Збільшує `score` на 10
- Порівнює `score` з 10
: `score += 10` — короткий запис для `score = score + 10`.

? Що виведе фрагмент?
| int a = 1, b = 2;
| a = b;
| b = a;
| cout << a << " " << b;
- `2 1`
+ `2 2`
- `1 1`
: Після `a = b` обидві змінні дорівнюють 2, і значення 1 втрачено. Для обміну потрібна допоміжна змінна.
```

## Практика

```exercise
id: piggy-bank
title: Скарбничка
level: 1
=== statement
У скарбничці було 50 гривень. Програма в редакторі вже створює змінну `money`. Допиши її:

1. додай до `money` 20 гривень і виведи `money`;
2. витрать 35 гривень і знову виведи `money`;
3. подвой суму і виведи `money` втретє.

Три числа виведи через пробіл в одному рядку.
=== example
---
70 35 70
=== starter
#include <iostream>
using namespace std;

int main() {
    int money = 50;
    // твій код тут

    return 0;
}
=== hint
Скористайся короткими записами `money += 20;`, `money -= 35;`, `money *= 2;`.
=== hint
Після кожної зміни виводь `money << " "`, а в кінці — `"\n"`.
=== solution
#include <iostream>
using namespace std;

int main() {
    int money = 50;
    money += 20;
    cout << money << " ";
    money -= 35;
    cout << money << " ";
    money *= 2;
    cout << money << "\n";
    return 0;
}
```

```exercise
id: swap
title: Обмін
level: 1
=== statement
У програмі є змінні `a = 3` і `b = 8`, а в кінці вони виводяться. Додай у середину програми команди, які поміняють значення змінних місцями, щоб програма вивела `8 3`.

Не змінюй числа 3 і 8 у перших рядках і рядок з `cout`.
=== example
---
8 3
=== starter
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 8;
    // поміняй значення a і b місцями

    cout << a << " " << b << "\n";
    return 0;
}
=== hint
Потрібна третя змінна: збережи в ній значення `a`, потім запиши в `a` значення `b`, а в `b` — збережене.
=== solution
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 8;
    int temp = a;
    a = b;
    b = temp;
    cout << a << " " << b << "\n";
    return 0;
}
```

```exercise
id: room
title: Кімната
level: 2
=== statement
Кімната має довжину 5 м, ширину 4 м і висоту 3 м. Створи змінні `length`, `width`, `height` з цими значеннями і обчисли:

- площу підлоги (довжина × ширина);
- площу всіх чотирьох стін (периметр підлоги × висота);
- об’єм кімнати (довжина × ширина × висота).

Виведи три числа через пробіл.
=== example
---
20 54 60
=== hint
Периметр підлоги — це `2 * (length + width)`.
=== solution
#include <iostream>
using namespace std;

int main() {
    int length = 5, width = 4, height = 3;
    int floorArea = length * width;
    int wallsArea = 2 * (length + width) * height;
    int volume = length * width * height;
    cout << floorArea << " " << wallsArea << " " << volume << "\n";
    return 0;
}
```

## Коротко

- Змінна — іменована комірка пам’яті; `int x;` оголошує змінну для цілих чисел.
- `=` — це присвоєння: обчисли праву частину і запиши в змінну ліворуч.
- `x += 5`, `x -= 5`, `x *= 2`, `x++`, `x--` — короткі записи для зміни змінної.
- Імена: латинські літери, цифри і `_`, не з цифри на початку; великі й малі літери різняться.
- Щоб поміняти значення двох змінних, потрібна допоміжна змінна.
