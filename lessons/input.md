# Введення даних

Досі наші програми щоразу виводили одне й те саме. Справжня програма отримує дані ззовні і для різних даних видає різні відповіді. Навчимося читати числа з клавіатури.

> [!NOTE] У цьому уроці
> - як прочитати число командою `cin`;
> - як прочитати кілька чисел одразу;
> - як побудована типова програма: введення, обчислення, виведення;
> - головне правило олімпіадних програм.

## Команда `cin`

`cin` (читається «сі-ін», від *character input*) — це клавіатура. Стрілка `>>` показує, куди йдуть дані: **з** `cin` **у** змінну.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << n * 2 << "\n";
    return 0;
}
```

```input
21
```

```output
42
```

Коли виконання доходить до `cin >> n;`, програма **зупиняється і чекає**, поки користувач набере число і натисне <kbd>Enter</kbd>. Число записується в змінну `n`, і програма йде далі.

> [!TIP] Як вводити дані на цьому сайті
> Під програмою видно приклад введення. Натисни «Змінити» — з’явиться поле «Введення для програми». Напиши туди інше число й натисни «Запустити». У Code::Blocks числа набирають у чорному вікні консолі.

Запам’ятати напрямок стрілок легко: `cout << x` — значення **виходить** на екран, `cin >> x` — значення **входить** у змінну.

## Кілька чисел

Кілька чисел читають однією командою:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << "\n";
    return 0;
}
```

```input
15 27
```

```output
42
```

Числа у введенні можна розділяти пробілами або переходами на новий рядок — `cin` пропускає всі пробіли і читає наступне число. Тому введення `15 27` і

```text
15
27
```

для цієї програми однакові.

Порядок важливий: перше число потрапить у `a`, друге — у `b`.

## Введення → обчислення → виведення

Майже кожна олімпіадна задача розв’язується за однією схемою:

1. **прочитати** вхідні дані;
2. **обчислити** відповідь;
3. **вивести** відповідь.

Наприклад, задача: «Дано сторони прямокутника `a` і `b`. Виведи його периметр і площу».

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. Введення
    int a, b;
    cin >> a >> b;

    // 2. Обчислення
    int perimeter = 2 * (a + b);
    int area = a * b;

    // 3. Виведення
    cout << perimeter << " " << area << "\n";
    return 0;
}
```

```input
3 5
```

```output
16 15
```

## Головне правило олімпіадних програм

У звичайних програмах ввічливо попросити користувача: «Введіть число». Але на олімпіаді дані вводить не людина, а **перевіряльна система**. Вона подає на вхід тест і порівнює виведення з правильною відповіддю. Будь-який зайвий текст — і відповідь неправильна.

```cpp
// Неправильно на олімпіаді:
cout << "Enter two numbers: ";
cin >> a >> b;
cout << "Sum = " << a + b << "\n";

// Правильно:
cin >> a >> b;
cout << a + b << "\n";
```

> [!IMPORTANT]
> Програма читає рівно те, що описано у вхідних даних, і виводить рівно те, що вимагають вихідні дані. Жодних підказок, пояснень і зайвих символів.

## Перевір себе

```quiz
? Що робить команда `cin >> x;`?
- Виводить значення `x` на екран
+ Чекає, поки користувач уведе значення, і записує його в `x`
- Очищає змінну `x`
: Дані йдуть із `cin` (клавіатури) у змінну `x`.

? Що виведе програма, якщо ввести `3 7`?
| int a, b;
| cin >> a >> b;
| cout << b << a;
- `37`
+ `73`
- `10`
: Спершу виводиться `b` (7), потім `a` (3), і без пробілу між ними.

? Задача: «Дано два числа, виведи їх суму». Як має виглядати виведення для введення `2 3`?
- `Sum = 5`
- `Enter numbers: 5`
+ `5`
: На олімпіаді виводять лише відповідь, без пояснень.

? Програма читає два числа: `cin >> a >> b;`. Як можна їх увести?
- Тільки в одному рядку через пробіл
- Тільки в різних рядках
+ І так, і так: `cin` пропускає пробіли та переходи на новий рядок
: Між числами може бути будь-яка кількість пробілів і переходів на новий рядок.
```

## Коротко

- `cin >> x;` чекає на введення і записує значення в `x`; `cin >> a >> b;` читає кілька значень.
- Між числами у введенні можуть бути пробіли або переходи на новий рядок.
- Схема розв’язку: прочитати → обчислити → вивести.
- На олімпіаді програма виводить лише відповідь, без підказок і пояснень.
