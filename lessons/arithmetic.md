# Арифметика і ділення націло

У цьому уроці — дві найкорисніші операції олімпіадного програміста: ділення націло `/` і остача від ділення `%`. З їхньою допомогою можна розібрати число на цифри, перевести секунди в години і хвилини, поділити цукерки порівну.

> [!NOTE] У цьому уроці
> - як ділять цілі числа і що таке остача;
> - як отримати цифри числа;
> - як переводити час і інші одиниці;
> - порядок виконання дій.

## Ділення націло

Пам’ятаєш, як у молодших класах ділили з остачею? «17 цукерок поділити між 5 дітьми: кожному по 3, і 2 залишається». Саме так ділить C++, коли обидва числа цілі:

- `/` — **ціла частина** від ділення (неповна частка);
- `%` — **остача** від ділення.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 17 / 5 << " " << 17 % 5 << "\n";
    cout << 20 / 4 << " " << 20 % 4 << "\n";
    cout << 3 / 5 << " " << 3 % 5 << "\n";
    return 0;
}
```

```output
3 2
5 0
0 3
```

Зверни увагу на останній рядок: 3 поділити на 5 — це 0 цілих і 3 в остачі (кожній із 5 дітей не дісталося жодної цукерки з трьох).

Ціла частина і остача завжди пов’язані: `a = (a / b) * b + a % b`. Наприклад, 17 = 3 · 5 + 2.

> [!WARNING]
> Ділити на нуль не можна: `x / 0` і `x % 0` аварійно зупиняють програму (вердикт RE). Якщо дільник може дорівнювати нулю, цей випадок треба перевірити окремо — як це робити, дізнаємося в уроці про умови.

## Парні і непарні числа

Число **парне**, якщо ділиться на 2 без остачі, тобто `n % 2` дорівнює 0. Якщо `n % 2` дорівнює 1 — число непарне.

Взагалі, `a % b == 0` означає «`a` ділиться на `b` націло». Наприклад, `15 % 5` — це 0, тож 15 ділиться на 5.

## Цифри числа

Ми записуємо числа в десятковій системі, тому ділення на 10 «відрізає» цифри:

- `n % 10` — **остання цифра** числа;
- `n / 10` — число **без останньої цифри**.

Для числа 4827: `4827 % 10` = 7, а `4827 / 10` = 482.

Так можна дістати будь-яку цифру. Для тризначного числа `n`:

| Цифра | Формула | Для 583 |
| --- | --- | --- |
| сотні | `n / 100` | 5 |
| десятки | `n / 10 % 10` | 8 |
| одиниці | `n % 10` | 3 |

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int hundreds = n / 100;
    int tens = n / 10 % 10;
    int ones = n % 10;
    cout << hundreds << " " << tens << " " << ones << "\n";
    cout << hundreds + tens + ones << "\n";
    return 0;
}
```

```input
583
```

```output
5 8 3
16
```

> [!TIP]
> Вираз `n / 10 % 10` виконується зліва направо: спершу `583 / 10` = 58, потім `58 % 10` = 8. Розібрати на цифри число будь-якої довжини навчимося в уроці про цикл `while`.

## Години, хвилини, секунди

Остача корисна всюди, де величини «переповнюються»: 60 секунд — це хвилина, 60 хвилин — година, 7 днів — тиждень.

Задача: дано кількість секунд `t`, виведи, скільки це годин, хвилин і секунд.

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    int hours = t / 3600;          // у годині 3600 секунд
    int minutes = t % 3600 / 60;   // що залишилося після годин — у хвилини
    int seconds = t % 60;          // залишок секунд
    cout << hours << " " << minutes << " " << seconds << "\n";
    return 0;
}
```

```input
10000
```

```output
2 46 40
```

Перевір: 2 · 3600 + 46 · 60 + 40 = 7200 + 2760 + 40 = 10000.

Ще один приклад — дні тижня. Якщо дні пронумеровано від 0 (понеділок) до 6 (неділя), то через `n` днів після дня `d` настане день `(d + n) % 7`. Остача «закільцьовує» номери: після 6 знову йде 0.

## Ділення з округленням угору

Задача: у класі `n` учнів, за партою сидять двоє. Скільки потрібно парт? Для 7 учнів потрібно 4 парти, хоча `7 / 2` = 3: «зайвому» учневі теж потрібна парта.

Ділення з округленням угору для додатних чисел робиться формулою `(n + k - 1) / k`, де `k` — скільки місць в одній «упаковці». Для парт: `(n + 1) / 2`.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << (7 + 1) / 2 << " " << (8 + 1) / 2 << "\n";   // парти для 7 і 8 учнів
    cout << (10 + 3 - 1) / 3 << "\n";   // скільки коробок по 3 для 10 речей
    return 0;
}
```

```output
4 4
4
```

## Порядок дій

`*`, `/` і `%` мають однаковий пріоритет і виконуються **зліва направо**, раніше за `+` і `-`.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 10 / 3 * 3 << "\n";   // (10 / 3) * 3 = 3 * 3
    cout << 10 * 3 / 4 << "\n";   // (10 * 3) / 4 = 30 / 4
    cout << 2 + 10 % 4 << "\n";   // 2 + (10 % 4) = 2 + 2
    return 0;
}
```

```output
9
7
4
```

> [!CAUTION]
> Через ділення націло порядок множення й ділення впливає на відповідь: `10 / 3 * 3` дає 9, а `10 * 3 / 3` дає 10. Якщо сумніваєшся — став дужки.

> [!NOTE] Від’ємні числа
> C++ відкидає дробову частину «в бік нуля»: `-7 / 2` дорівнює `-3`, а `-7 % 2` дорівнює `-1` (знак остачі такий, як у діленого). Пам’ятай про це, якщо в задачі трапляються від’ємні числа.

## Коротко

- Для цілих чисел `/` дає цілу частину, а `%` — остачу від ділення.
- `n % 2 == 0` — число парне; `a % b == 0` — `a` ділиться на `b`.
- `n % 10` — остання цифра, `n / 10` — число без останньої цифри.
- Остача «закільцьовує» величини: хвилини, години, дні тижня.
- Ділення з округленням угору: `(n + k - 1) / k`.
- `*`, `/`, `%` виконуються зліва направо, раніше за `+` і `-`.
