# Графи: обхід у глибину і в ширину

Міста і дороги між ними, друзі в соцмережі, клітинки лабіринту і проходи між ними — усе це **графи**. Графи — велика тема, але для районних і обласних олімпіад найчастіше потрібні дві речі: обійти граф і знайти найкоротший шлях. Ними й займемося.

> [!NOTE] У цьому уроці
> - що таке граф, вершини, ребра, степінь вершини;
> - як зберігати граф у програмі: список суміжності;
> - обхід у глибину (DFS) і компоненти зв’язності;
> - обхід у ширину (BFS) і найкоротші шляхи;
> - графи на клітчастому полі.

## Що таке граф

**Граф** складається з **вершин** (міста, люди, клітинки) і **ребер** — зв’язків між парами вершин (дороги, дружба, сусідство). Вершини зазвичай нумерують від 1 до `n`, а ребер у графі `m`.

- Граф **неорієнтований**, якщо ребро з’єднує вершини в обидва боки (дорога з двостороннім рухом). Якщо ребра мають напрям (односторонні дороги), граф **орієнтований**.
- **Степінь** вершини — кількість ребер, що з неї виходять.
- **Шлях** — послідовність вершин, сусідні з яких з’єднані ребрами. Довжина шляху — кількість ребер у ньому.
- Граф **зв’язний**, якщо з будь-якої вершини можна дійти до будь-якої іншої.

## Як зберігати граф

Найзручніший спосіб — **список суміжності**: для кожної вершини зберігаємо список її сусідів.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);       // g[v] — сусіди вершини v
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);              // граф неорієнтований: ребро в обидва боки
    }
    for (int v = 1; v <= n; v++) {
        cout << v << ":";
        for (int u : g[v]) cout << " " << u;
        cout << "\n";
    }
    return 0;
}
```

```input
4 3
1 2
1 3
3 4
```

```output
1: 2 3
2: 1
3: 1 4
4: 3
```

Степінь вершини `v` — це просто `g[v].size()`.

> [!TIP]
> Існує й **матриця суміжності**: таблиця `n × n`, де `a[i][j] = 1`, якщо є ребро між `i` і `j`. Вона зручна для маленьких графів (n до кількох тисяч), але займає n² пам’яті. Список суміжності займає лише n + m і підходить для графів з сотнями тисяч вершин.

## Обхід у глибину (DFS)

**Обхід у глибину** (*depth-first search*) — як дослідження печери: йдемо від вершини до будь-якого ще не відвіданого сусіда, від нього — далі, а коли йти нікуди, повертаємося назад. Записується він рекурсією в кілька рядків:

```cpp
vector<vector<int>> g;
vector<bool> used;

void dfs(int v) {
    used[v] = true;            // позначаємо вершину відвіданою
    for (int u : g[v]) {
        if (!used[u]) dfs(u);  // ідемо в кожного невідвіданого сусіда
    }
}
```

Масив `used` не дає ходити по колу: у кожну вершину заходимо один раз. Тому DFS працює за O(n + m).

Після виклику `dfs(1)` позначеними виявляться **всі вершини, досяжні з першої**. Звідси корисні застосування:

- **чи можна дістатися** з `a` в `b` — запусти `dfs(a)` і перевір `used[b]`;
- **компоненти зв’язності** — «острівці» графа, між якими немає шляхів. Перебираємо вершини; знайшовши невідвідану, запускаємо з неї DFS і збільшуємо лічильник компонент.

```cpp
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> g;
vector<bool> used;

void dfs(int v) {
    used[v] = true;
    for (int u : g[v]) {
        if (!used[u]) dfs(u);
    }
}

int main() {
    int n, m;
    cin >> n >> m;
    g.assign(n + 1, {});
    used.assign(n + 1, false);
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    int components = 0;
    for (int v = 1; v <= n; v++) {
        if (!used[v]) {
            components++;
            dfs(v);
        }
    }
    cout << components << "\n";
    return 0;
}
```

```input
6 3
1 2
2 3
5 6
```

```output
3
```

Компоненти: {1, 2, 3}, {4} і {5, 6}.

> [!WARNING]
> Рекурсивний DFS на дуже довгому «ланцюжку» з сотень тисяч вершин може переповнити стек викликів. На більшості олімпіад стек достатньо великий, але якщо програма падає з RE — спробуй BFS, який працює без рекурсії.

## Обхід у ширину (BFS)

**Обхід у ширину** (*breadth-first search*) поширюється від початкової вершини «хвилями», як коло на воді від кинутого камінця: спершу всі сусіди (відстань 1), потім їхні сусіди (відстань 2) і так далі. Тому BFS знаходить **найкоротші шляхи** (за кількістю ребер) від початкової вершини до всіх інших.

Вершини, що чекають обробки, тримають у черзі `queue`:

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    vector<int> dist(n + 1, -1);     // -1 — ще не відвідано
    queue<int> q;
    dist[1] = 0;
    q.push(1);
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int u : g[v]) {
            if (dist[u] == -1) {      // уперше бачимо u — це найкоротший шлях до нього
                dist[u] = dist[v] + 1;
                q.push(u);
            }
        }
    }
    for (int v = 1; v <= n; v++) cout << dist[v] << " ";
    cout << "\n";
    return 0;
}
```

```input
5 5
1 2
1 3
2 4
3 4
4 5
```

```output
0 1 1 2 3 
```

Відстань `-1` залишиться у вершин, до яких шляху немає. Складність BFS — теж O(n + m).

> [!IMPORTANT]
> Щоб відновити сам шлях, а не лише його довжину, для кожної вершини запам’ятовують, з якої вершини в неї прийшли: `parent[u] = v`. Потім від кінцевої вершини йдуть за `parent` назад до початкової і перевертають отриманий список.

## Графи на клітчастому полі

Лабіринт з клітинок — теж граф: вершини — вільні клітинки, ребра — між сусідніми вільними клітинками. Список суміжності будувати не потрібно: сусідів перебираємо масивами зміщень, як в уроці про двовимірні масиви. А `dist` стає двовимірним.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (auto &row : g) cin >> row;
    int di[4] = {-1, 1, 0, 0}, dj[4] = {0, 0, -1, 1};
    vector<vector<int>> dist(n, vector<int>(m, -1));
    queue<pair<int, int>> q;
    dist[0][0] = 0;
    q.push({0, 0});
    while (!q.empty()) {
        auto [i, j] = q.front();       // беремо обидві координати з пари
        q.pop();
        for (int k = 0; k < 4; k++) {
            int ni = i + di[k], nj = j + dj[k];
            if (ni >= 0 && ni < n && nj >= 0 && nj < m && g[ni][nj] == '.' && dist[ni][nj] == -1) {
                dist[ni][nj] = dist[i][j] + 1;
                q.push({ni, nj});
            }
        }
    }
    cout << dist[n - 1][m - 1] << "\n";
    return 0;
}
```

```input
4 5
..#..
.##.#
.....
#.##.
```

```output
7
```

Запис `auto [i, j] = q.front();` одразу розкладає пару на дві змінні — `i` (перший елемент) і `j` (другий).

## Перевір себе

```quiz
? Скільки разів кожне ребро неорієнтованого графа записується в список суміжності?
- Один
+ Двічі: у списку кожного з двох кінців
- Жодного
: Ребро a–b додає `b` до сусідів `a` і `a` до сусідів `b`.

? Навіщо в DFS масив `used`?
+ Щоб не заходити у вершину вдруге і не ходити по колу
- Щоб рахувати відстані
- Щоб зберігати ребра
: Без позначок DFS на графі з циклом працював би нескінченно.

? Який обхід знаходить найкоротший шлях (за кількістю ребер)?
- DFS
+ BFS
- Будь-який
: BFS обходить вершини в порядку зростання відстані від початкової.

? Граф має 7 вершин і жодного ребра. Скільки в ньому компонент зв’язності?
- 1
- 0
+ 7
: Кожна вершина — окрема компонента.

? Яка складність BFS для графа з `n` вершинами і `m` ребрами?
- O(n · m)
+ O(n + m)
- O(n²)
: Кожна вершина потрапляє в чергу один раз, кожне ребро переглядається сталу кількість разів.
```

```exercise
=== hint
Перебирай клітинки; знайшовши суходіл, який ще не відвідано, збільш лічильник і обійди весь острів (BFS або DFS по чотирьох сусідах).
=== solution
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<string> g(n);
    for (auto &row : g) cin >> row;
    vector<vector<bool>> used(n, vector<bool>(m, false));
    int di[4] = {-1, 1, 0, 0}, dj[4] = {0, 0, -1, 1};
    int islands = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (g[i][j] != '#' || used[i][j]) continue;
            islands++;
            queue<pair<int, int>> q;
            used[i][j] = true;
            q.push({i, j});
            while (!q.empty()) {
                auto [x, y] = q.front();
                q.pop();
                for (int k = 0; k < 4; k++) {
                    int nx = x + di[k], ny = y + dj[k];
                    if (nx >= 0 && nx < n && ny >= 0 && ny < m && g[nx][ny] == '#' && !used[nx][ny]) {
                        used[nx][ny] = true;
                        q.push({nx, ny});
                    }
                }
            }
        }
    }
    cout << islands << "\n";
    return 0;
}
```

```exercise
id: is-tree
title: Чи дерево

=== input
У першому рядку — числа `n` і `m` (1 ≤ n ≤ 10⁵, 0 ≤ m ≤ 10⁵). Далі `m` рядків з ребрами `a b` (a ≠ b, кратних ребер немає).
=== output
`YES` або `NO`.
=== example

1 3
3 4
---
YES
=== example
4 3
1 2
2 3
1 3
---

=== test

---
YES
=== test

---

=== test
5 4

=== hint
Перевір дві умови: `m == n − 1` і граф зв’язний (DFS чи BFS з вершини 1 відвідує всі вершини).
=== solution
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> g(n + 1);
    for (int i = 0; i < m; i++) {
        int a, b;
        cin >> a >> b;
        g[a].push_back(b);
        g[b].push_back(a);
    }
    vector<bool> used(n + 1, false);
    queue<int> q;
    used[1] = true;
    q.push(1);
    int visited = 1;
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int u : g[v]) {
            if (!used[u]) {
                used[u] = true;
                visited++;
                q.push(u);
            }
        }
    }
    cout << (m == n - 1 && visited == n ? "YES" : "NO") << "\n";
    return 0;
}
```

## Коротко

- Граф — вершини і ребра; зберігай його списком суміжності `vector<vector<int>> g(n + 1)`.
- DFS: рекурсія з масивом `used`; знаходить досяжні вершини і компоненти зв’язності.
- BFS: черга і масив `dist`; знаходить найкоротші шляхи за кількістю ребер.
- Обидва обходи працюють за O(n + m).
- Клітчасте поле — теж граф: сусідів перебирають масивами зміщень.
