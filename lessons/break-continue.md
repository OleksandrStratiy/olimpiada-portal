# break, continue і дільники

Іноді цикл не потрібно доводити до кінця: відповідь знайдено — можна зупинитися. А іноді деякі ітерації треба пропустити. Для цього є команди `break` і `continue`. А ще в цьому уроці розберемо дільники і прості числа — улюблену тему олімпіадних задач.

> [!NOTE] У цьому уроці
> - `break` — достроковий вихід із циклу;
> - `continue` — перехід до наступної ітерації;
> - як знайти всі дільники числа, і швидко;
> - як перевірити, чи є число простим.

## `break`: вийти з циклу

Команда `break` негайно завершує цикл, у якому вона стоїть. Програма продовжує роботу з першої команди після циклу.

Знайдемо перше число, більше за `n`, яке ділиться на 7:

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int x = n + 1; ; x++) {
        if (x % 7 == 0) {
            cout << x << "\n";
            break;
        }
    }
    return 0;
}
```

```input
30
```

```output
35
```

Зверни увагу: у цьому `for` немає умови (між двома `;` порожньо) — без `break` цикл був би нескінченним. Те саме часто записують як `while (true) { … }`.

## `continue`: пропустити решту ітерації

`continue` не завершує цикл, а одразу переходить до наступної ітерації, пропускаючи команди, що залишилися в тілі.

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue;          // числа, кратні 3, пропускаємо
        }
        cout << i << " ";
    }
    cout << "\n";
    return 0;
}
```

```output
1 2 4 5 7 8 10
```

> [!TIP]
> `break` і `continue` роблять код коротшим, але без них завжди можна обійтися за допомогою умов і прапорців. Користуйся ними, коли так зрозуміліше.

## Дільники числа

**Дільник** числа `n` — це число `d`, на яке `n` ділиться без остачі (`n % d == 0`). Найпростіше перебрати всі числа від 1 до `n`:

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int d = 1; d <= n; d++) {
        if (n % d == 0) {
            cout << d << " ";
        }
    }
    cout << "\n";
    return 0;
}
```

```input
36
```

```output
1 2 3 4 6 9 12 18 36
```

Цей спосіб робить `n` перевірок. Для `n` до мільйона це миттєво, а от для 10¹² — надто довго.

### Швидкий спосіб: до кореня

Подивись на дільники числа 36: вони утворюють пари, добуток яких дорівнює 36: 1 · 36, 2 · 18, 3 · 12, 4 · 9, 6 · 6. У кожній парі **менший дільник не перевищує √36 = 6**. Тому досить перебрати `d` від 1 до √n, а другий дільник пари отримати як `n / d`.

Умову `d <= sqrt(n)` зручно записати без дробових чисел: `d * d <= n`.

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int count = 0;
    for (long long d = 1; d * d <= n; d++) {
        if (n % d == 0) {
            count++;                    // дільник d
            if (d != n / d) count++;    // і парний до нього n / d
        }
    }
    cout << count << "\n";
    return 0;
}
```

```input
36
```

```output
9
```

Для 6 · 6 обидва дільники пари однакові, тому другий раз 6 не рахуємо — звідси перевірка `d != n / d`. Тепер для `n = 10¹²` знадобиться лише мільйон перевірок замість трильйона.

## Прості числа

Число називається **простим**, якщо воно більше за 1 і ділиться лише на 1 і на себе: 2, 3, 5, 7, 11, 13… Число, більше за 1, яке не є простим, називається **складеним**. Число 1 не є ні простим, ні складеним.

Щоб перевірити, чи `n` просте, шукаємо дільник від 2 до √n. Знайшли — число складене, і далі шукати немає сенсу:

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    bool prime = (n >= 2);
    for (long long d = 2; d * d <= n; d++) {
        if (n % d == 0) {
            prime = false;
            break;          // дільник знайдено — далі шукати не треба
        }
    }
    cout << (prime ? "YES" : "NO") << "\n";
    return 0;
}
```

```input
97
```

```output
YES
```

> [!IMPORTANT]
> Чому досить перевіряти до √n? Якщо `n = a · b` і обидва множники більші за √n, то їхній добуток більший за n — суперечність. Отже, якщо в числа є дільник, то є й дільник, не більший за √n.

> [!CAUTION]
> У виразі `d * d <= n` добуток може переповнити `int`, якщо `n` близьке до 2·10⁹. Роби `d` типу `long long`. І не забувай, що 1 — не просте число, а 2 — просте.

## Коротко

- `break` завершує цикл, `continue` переходить до наступної ітерації.
- `for (…; ; …)` чи `while (true)` без `break` — нескінченний цикл.
- Дільники утворюють пари `d` і `n / d`; досить перебирати `d`, поки `d * d <= n`.
- Число просте, якщо воно більше за 1 і не має дільників від 2 до √n.
- Для `d * d` при великих `n` використовуй `long long`.
