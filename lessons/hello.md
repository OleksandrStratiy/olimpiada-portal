# Перша програма

За традицією, вивчення будь-якої мови програмування починають із програми, яка вітається зі світом. Розберемо її по рядках: у ній уже є все, з чого складається кожна програма на C++.

> [!NOTE] У цьому уроці
> - з яких частин складається програма;
> - як вивести текст на екран за допомогою `cout`;
> - як перейти на новий рядок;
> - що таке коментарі;
> - як читати повідомлення про помилки компіляції.

## Програма Hello, world!

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
```

```output
Hello, world!
```

Тут шість рядків (порожній не рахуємо). Розберемо кожен.

### `#include <iostream>`

Підключає **бібліотеку** `iostream` — набір готових інструментів для введення і виведення (*input/output stream* — «потік введення-виведення»). Без цього рядка компілятор не знатиме, що таке `cout`. Бібліотеки підключають на самому початку програми.

### `using namespace std;`

Усі стандартні інструменти C++ «живуть» у просторі імен `std` (від *standard*). Цей рядок дозволяє писати просто `cout` замість довшого `std::cout`. Поки що просто пиши його в кожній програмі.

### `int main() { … }`

Це **головна функція** програми. Коли програма запускається, комп’ютер шукає `main` і починає виконувати команди, що стоять між фігурними дужками `{` і `}`. Дужки позначають початок і кінець головної функції.

### `cout << "Hello, world!" << endl;`

Ось команда, яка щось робить: виводить текст на екран.

- `cout` (читається «сі-аут», від *character output*) — це екран, куди виводиться текст.
- `<<` — стрілка, яка «відправляє» те, що праворуч, у `cout`.
- `"Hello, world!"` — текст, який треба вивести. Текст завжди пишуть у **подвійних лапках**, а самі лапки на екран не виводяться.
- `endl` (*end line*) — «кінець рядка»: перейти на новий рядок.
- `;` — **крапка з комою** закінчує команду. Як крапка в кінці речення.

### `return 0;`

Завершує роботу програми і повідомляє, що все пройшло успішно (0 означає «без помилок»).

> [!IMPORTANT]
> Цей «каркас» буде в кожній твоїй програмі:
> ```cpp
> #include <iostream>
> using namespace std;
>
> int main() {
>     // тут твої команди
>     return 0;
> }
> ```
> Запам’ятай його напам’ять — далі ми змінюватимемо лише те, що всередині `main`.

## Кілька команд

Команди виконуються по черзі, згори донизу. Кожен `cout` продовжує виводити з того місця, де зупинився попередній.

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "One" << endl;
    cout << "Two" << endl;
    cout << "Three" << endl;
    return 0;
}
```

```output
One
Two
Three
```

А що буде без `endl`? Тоді весь текст опиниться в одному рядку:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "One";
    cout << "Two";
    cout << "Three";
    return 0;
}
```

```output
OneTwoThree
```

Зверни увагу: між словами немає навіть пробілів. Комп’ютер виводить **рівно те**, що написано в лапках, і нічого не додає від себе. Пробіл — це теж символ, і його треба написати:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "One " << "Two " << "Three" << endl;
    return 0;
}
```

```output
One Two Three
```

В одній команді може бути кілька `<<`: вони виконуються зліва направо.

## Новий рядок: `endl` і `"\n"`

Перейти на новий рядок можна ще одним способом — написати в тексті `\n`. Це два символи (зворотна коса риска і літера n), але разом вони означають один спеціальний символ «новий рядок».

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "First line\nSecond line\n";
    cout << "Third line" << "\n";
    return 0;
}
```

```output
First line
Second line
Third line
```

`endl` і `"\n"` дають той самий результат. Але `"\n"` працює швидше, тому на олімпіадах, де програма може виводити сотні тисяч рядків, пишуть саме його. Далі в курсі ми теж частіше писатимемо `"\n"`.

## Коментарі

**Коментар** — це примітка для людей, яку компілятор пропускає. Коментарі пояснюють, що робить код.

- `//` — коментар до кінця рядка;
- `/* … */` — коментар на кілька рядків.

```cpp
#include <iostream>
using namespace std;

int main() {
    // Ця програма вітається
    cout << "Hi!" << "\n"; // виводимо привітання
    /* А цей рядок компілятор
       пропустить повністю: cout << "Bye"; */
    return 0;
}
```

```output
Hi!
```

> [!TIP]
> Коментарі можна писати українською — компілятор їх не читає. А ще коментарем зручно тимчасово «вимкнути» рядок коду, не видаляючи його.

## Помилки компіляції

Помилки роблять усі — і новачки, і чемпіони світу. Важливо вміти їх швидко знаходити. Якщо в коді помилка, компілятор не створить програму, а надрукує повідомлення. Подивимося на типові помилки. Біля кожної програми є кнопка «Запустити» — натисни її, щоб побачити, що скаже компілятор.

### Пропущена крапка з комою

```cpp error
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world!" << endl
    return 0;
}
```

Компілятор відповість приблизно так:

```text
main.cpp:5:36: error: expected ';' before 'return'
```

Як читати це повідомлення:

- `main.cpp:5:36` — назва файлу, **номер рядка** (5) і номер символу в рядку (36);
- `error` — це помилка (а `warning` — лише попередження, програма все одно запуститься);
- `expected ';' before 'return'` — «очікувалася `;` перед `return`».

Компілятор помітив проблему, лише коли дійшов до `return`, тому часто помилка насправді в **попередньому** рядку.

### Велика літера замість малої

```cpp error
#include <iostream>
using namespace std;

int main() {
    Cout << "Hello, world!" << endl;
    return 0;
}
```

```text
main.cpp:5:5: error: 'Cout' was not declared in this scope
```

«`Cout` не оголошено». C++ розрізняє великі й малі літери: `cout`, `Cout` і `COUT` — це три різні слова, і правильне лише перше. Так само `Main` замість `main` — помилка.

### Незакриті лапки

```cpp error
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world! << endl;
    return 0;
}
```

```text
main.cpp:5:13: error: missing terminating " character
```

«Немає завершального символу `"`». Кожні лапки мають пару.

> [!CAUTION]
> Найчастіші помилки новачків:
> - пропущена `;` у кінці команди;
> - велика літера там, де має бути мала (`Cout`, `Main`, `Return`);
> - непарні лапки або дужки;
> - українська літера чи друкарські лапки «» у коді поза текстом у лапках.

> [!TIP]
> Якщо помилок кілька, виправляй **першу** і компілюй знову. Часто одна помилка «тягне» за собою ще кілька повідомлень, які зникнуть разом із нею.

## Перевір себе

```quiz
? З чого починається виконання програми на C++?
- З першого рядка файлу
+ З функції `main`
- З рядка `#include <iostream>`
: Програма починає роботу з функції `main` — виконуються команди між її фігурними дужками.

| cout << "Cat";

? Яким символом закінчується майже кожна команда в C++?
- Крапкою `.`
+ Крапкою з комою `;`
- Двокрапкою `:`
: Крапка з комою — це кінець команди, як крапка в кінці речення.

? Компілятор пише `error: 'Cout' was not declared in this scope`. Що не так?
- Пропущено крапку з комою
+ Слово `cout` написано з великої літери
- Не вистачає лапок
: C++ розрізняє великі й малі літери, правильно — `cout`.

? Що з цього **не** потрапить на екран?
- Текст у лапках після `cout <<`
+ Текст після `//`
- Пробіл у лапках `" "`
: `//` починає коментар, який компілятор пропускає.

- `endl` переходить на новий рядок, а `"\n"` — ні

- `"\n"` виводить на екран символи \ і n

```

## Коротко

- Кожна програма має каркас: `#include <iostream>`, `using namespace std;`, `int main() { … return 0; }`.
- `cout << "текст";` виводить текст; `endl` або `"\n"` — перехід на новий рядок.
- Команди виконуються по черзі і закінчуються `;`.
- `//` і `/* … */` — коментарі, компілятор їх пропускає.
- Повідомлення про помилку вказує номер рядка; часто помилка в рядку перед ним. Виправляй першу помилку і компілюй знову.
