# Параметри-посилання

Спробуймо написати функцію, яка міняє значення двох змінних місцями. Здається, це просто — але перша спроба не спрацює. Розберемося чому і як це виправити за допомогою **посилань**.

> [!NOTE] У цьому уроці
> - чому функція отримує копії аргументів;
> - параметри-посилання `int &x`;
> - як повернути з функції кілька результатів;
> - як передавати масиви у функції без копіювання.

## Функція отримує копію

```cpp
#include <iostream>
using namespace std;

void trySwap(int a, int b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 1, y = 2;
    trySwap(x, y);
    cout << x << " " << y << "\n";
    return 0;
}
```

```output
1 2
```

Нічого не змінилося! Річ у тім, що параметри `a` і `b` — це **нові змінні**, у які при виклику **копіюються** значення `x` і `y`. Функція чесно поміняла місцями свої копії, а оригінали в `main` залишилися як були. Це називається **передачею за значенням**.

## Посилання: `&`

Щоб функція працювала з самою змінною, а не з копією, параметр оголошують як **посилання** — дописують `&` після типу:

```cpp
#include <iostream>
using namespace std;

void mySwap(int &a, int &b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 1, y = 2;
    mySwap(x, y);
    cout << x << " " << y << "\n";
    return 0;
}
```

```output
2 1
```

Тепер `a` — це не копія, а **інше ім’я тієї самої змінної** `x`. Усе, що функція робить з `a`, насправді відбувається з `x`.

> [!IMPORTANT]
> Посилання — це псевдонім: друге ім’я для вже наявної змінної. Тому аргументом для параметра-посилання може бути лише змінна, а не число чи вираз: `mySwap(x, 5)` не скомпілюється.

## Кілька результатів

`return` повертає лише одне значення. А якщо функція має знайти і мінімум, і максимум? Результати можна «повернути» через параметри-посилання:

```cpp
#include <iostream>
using namespace std;

void divide(int a, int b, int &quotient, int &remainder) {
    quotient = a / b;
    remainder = a % b;
}

int main() {
    int q, r;
    divide(17, 5, q, r);
    cout << q << " " << r << "\n";
    return 0;
}
```

```output
3 2
```

## Масиви у функціях

Масив `vector`, переданий за значенням, теж **копіюється** — увесь, з усіма елементами. Це має два наслідки:

1. зміни елементів усередині функції не потрапляють в оригінал;
2. копіювання великого масиву забирає час: якщо функцію викликають багато разів, програма може не вкластися в обмеження часу.

Тому масиви майже завжди передають за посиланням:

- `vector<int> &a` — функція може **змінювати** масив;
- `const vector<int> &a` — функція лише **читає** масив; слово `const` забороняє його змінювати, а копіювання все одно немає.

```cpp
#include <iostream>
#include <vector>
using namespace std;

void readArray(vector<int> &a) {
    for (int &x : a) cin >> x;
}

long long sumOf(const vector<int> &a) {
    long long s = 0;
    for (int x : a) s += x;
    return s;
}

void doubleAll(vector<int> &a) {
    for (int &x : a) x *= 2;
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    readArray(a);
    doubleAll(a);
    cout << sumOf(a) << "\n";
    return 0;
}
```

```input
3
1 2 3
```

```output
12
```

Пам’ятаєш цикл `for (int &x : a)` з уроку про масиви? Тепер зрозуміло, що там означає `&`: `x` — посилання на черговий елемент, тому зміна `x` змінює сам елемент.

> [!TIP]
> Просте правило для олімпіад: числа (`int`, `long long`, `double`, `char`) передавай за значенням, якщо функція не повинна їх змінювати; масиви і рядки передавай як `const vector<int> &` чи `const string &`, а якщо функція їх змінює — без `const`.

## Перевір себе

```quiz
? Що виведе програма?
| void f(int x) { x = 100; }
| …
| int a = 5;
| f(a);
| cout << a;
+ 5
- 100
- Помилка компіляції
: Параметр `x` — копія `a`. Зміна копії не впливає на оригінал.

? Що виведе програма?
| void f(int &x) { x = 100; }
| …
| int a = 5;
| f(a);
| cout << a;
- 5
+ 100
- Помилка компіляції
: `x` — посилання на `a`, тож присвоєння змінює саме `a`.

? Навіщо писати `const vector<int> &a` замість `vector<int> a`?
- Щоб функція могла змінювати масив
+ Щоб не копіювати масив, а `const` захищав його від випадкових змін
- Це одне й те саме
: Посилання усуває копіювання, а `const` забороняє змінювати масив усередині функції.

? Який виклик не скомпілюється для функції `void inc(int &x)`?
- `inc(a);`
+ `inc(5);`
- `inc(arr[0]);`
: Посилання має вказувати на змінну. Число 5 — не змінна.
```

```exercise
id: sort3
title: Три числа за зростанням
level: 1
=== statement
Напиши функцію `void mySwap(int &a, int &b)` і за її допомогою впорядкуй три числа за зростанням. Наприклад: якщо `a > b`, поміняй їх; потім якщо `b > c` — поміняй; потім знову перевір `a` і `b`.
=== input
Три цілих числа, кожне за модулем не більше 10⁹.
=== output
Ті самі числа в порядку неспадання.
=== example
3 1 2
---
1 2 3
=== test
1 2 3
---
1 2 3
=== test
3 2 1
---
1 2 3
=== test
5 5 1
---
1 5 5
=== test
-1 -1000000000 1000000000
---
-1000000000 -1 1000000000
=== solution
#include <iostream>
using namespace std;

void mySwap(int &a, int &b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int a, b, c;
    cin >> a >> b >> c;
    if (a > b) mySwap(a, b);
    if (b > c) mySwap(b, c);
    if (a > b) mySwap(a, b);
    cout << a << " " << b << " " << c << "\n";
    return 0;
}
```

```exercise
id: min-max-ref
title: Мінімум і максимум однією функцією
level: 1
=== statement
Напиши функцію `void minMax(const vector<int> &a, int &mn, int &mx)`, яка знаходить найменший і найбільший елементи масиву. Прочитай масив і виведи мінімум і максимум.
=== input
У першому рядку — число `n` (1 ≤ n ≤ 10⁵). У другому — `n` цілих чисел, кожне за модулем не більше 10⁹.
=== output
Мінімум і максимум через пробіл.
=== example
5
4 -2 7 0 7
---
-2 7
=== test
1
3
---
3 3
=== test
3
-5 -6 -4
---
-6 -4
=== solution
#include <iostream>
#include <vector>
using namespace std;

void minMax(const vector<int> &a, int &mn, int &mx) {
    mn = a[0];
    mx = a[0];
    for (int x : a) {
        if (x < mn) mn = x;
        if (x > mx) mx = x;
    }
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a) cin >> x;
    int mn, mx;
    minMax(a, mn, mx);
    cout << mn << " " << mx << "\n";
    return 0;
}
```

```exercise
id: add-minutes
title: Час через k хвилин
level: 2
=== statement
Годинник показує `h` годин `m` хвилин. Що він показуватиме через `k` хвилин? Напиши функцію `void addMinutes(int &h, int &m, int k)`, яка змінює `h` і `m`. Пам’ятай, що після 23:59 настає 00:00.
=== input
Три цілих числа `h`, `m`, `k` (0 ≤ h ≤ 23, 0 ≤ m ≤ 59, 0 ≤ k ≤ 10⁹).
=== output
Два числа: години і хвилини.
=== example
10 30 45
---
11 15
=== example
23 50 20
---
0 10
=== test
0 0 0
---
0 0
=== test
0 0 1440
---
0 0
=== test
12 0 1000000000
---
22 40
=== hint
Переведи час у хвилини від початку доби: `t = h * 60 + m + k`. Потім візьми остачу від ділення на 1440 (кількість хвилин у добі) і знову розклади на години й хвилини. Використай `long long`.
=== solution
#include <iostream>
using namespace std;

void addMinutes(int &h, int &m, int k) {
    long long t = (long long)h * 60 + m + k;
    t %= 1440;
    h = t / 60;
    m = t % 60;
}

int main() {
    int h, m, k;
    cin >> h >> m >> k;
    addMinutes(h, m, k);
    cout << h << " " << m << "\n";
    return 0;
}
```

```exercise
id: reverse-part
title: Розворот частини масиву
level: 2
=== statement
Напиши функцію `void reversePart(vector<int> &a, int l, int r)`, яка перевертає частину масиву від елемента з номером `l` до елемента з номером `r` включно (нумерація з одиниці). Прочитай масив і `q` запитів, виконай їх по черзі і виведи масив.
=== input
У першому рядку — числа `n` і `q` (1 ≤ n ≤ 1000, 1 ≤ q ≤ 1000). У другому — `n` цілих чисел. Далі `q` рядків, у кожному два числа `l` і `r` (1 ≤ l ≤ r ≤ n).
=== output
Масив після всіх розворотів.
=== example
5 1
1 2 3 4 5
2 4
---
1 4 3 2 5
=== example
5 2
1 2 3 4 5
1 5
1 2
---
4 5 3 2 1
=== test
1 1
7
1 1
---
7
=== test
4 2
1 2 3 4
1 4
1 4
---
1 2 3 4
=== hint
Усередині функції міняй місцями `a[i]` і `a[j]`, рухаючи `i` від `l − 1` вправо, а `j` від `r − 1` вліво, поки `i < j`.
=== solution
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void reversePart(vector<int> &a, int l, int r) {
    int i = l - 1, j = r - 1;
    while (i < j) {
        swap(a[i], a[j]);
        i++;
        j--;
    }
}

int main() {
    int n, q;
    cin >> n >> q;
    vector<int> a(n);
    for (int &x : a) cin >> x;
    for (int k = 0; k < q; k++) {
        int l, r;
        cin >> l >> r;
        reversePart(a, l, r);
    }
    for (int x : a) cout << x << " ";
    cout << "\n";
    return 0;
}
```

## Коротко

- Звичайний параметр — копія аргументу; зміни копії не впливають на оригінал.
- Параметр-посилання `int &x` — друге ім’я змінної; функція змінює саму змінну.
- Через посилання функція може «повернути» кілька результатів.
- Масиви і рядки передавай за посиланням: `const vector<int> &a` — лише читати, `vector<int> &a` — змінювати.
