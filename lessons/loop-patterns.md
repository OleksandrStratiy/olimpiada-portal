# Типові задачі з циклами

Багато олімпіадних задач починаються однаково: «Дано `n` чисел…». У цьому уроці зберемо «рецепти» для найчастіших дій з послідовністю чисел. Їх варто знати напам’ять.

> [!NOTE] У цьому уроці
> - сума, кількість і середнє значення;
> - мінімум, максимум і номер максимуму;
> - послідовність, що закінчується нулем, і читання до кінця введення;
> - прапорці: «чи всі числа…», «чи є хоча б одне…»;
> - порівняння з попереднім числом.

## Сума і кількість

Ти вже вмієш читати `n` чисел у циклі. Додамо підрахунок: скільки серед них додатних і яка їхня сума.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long sum = 0;
    int count = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x > 0) {
            sum += x;
            count++;
        }
    }
    cout << count << " " << sum << "\n";
    return 0;
}
```

```input
6
3 -1 4 -1 5 -9
```

```output
3 12
```

Лічильник `count` — теж накопичувач, тільки до нього щоразу додається 1. Середнє значення — це сума, поділена на кількість. Не забудь перевірити, що кількість не нуль, і поділити як дробові числа: `(double)sum / count`.

## Мінімум і максимум

Як знайти найбільше число, якщо ми бачимо числа по одному? Так само, як людина в черзі вибирає найвищого: пам’ятає найвищого з тих, кого вже бачила, і порівнює з ним кожного наступного.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int best;
    cin >> best;                      // перше число — поки що найбільше
    for (int i = 1; i < n; i++) {     // решта n − 1 чисел
        int x;
        cin >> x;
        if (x > best) {
            best = x;
        }
    }
    cout << best << "\n";
    return 0;
}
```

```input
5
3 8 -2 8 6
```

```output
8
```

> [!WARNING] Чим заповнити `best` на початку
> Не пиши `int best = 0;` — якщо всі числа від’ємні, програма виведе 0, якого серед них немає. Найнадійніше взяти за початкове значення **перше число** послідовності, як у прикладі. Інший варіант — число, свідомо менше за будь-яке можливе, наприклад `-2000000000`, якщо в умові сказано, що числа за модулем не більші за 10⁹.

### Номер максимуму

Часто потрібне не саме значення, а його **номер** (позицію). Запам’ятовуємо номер разом зі значенням:

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int best, pos = 1;
    cin >> best;
    for (int i = 2; i <= n; i++) {
        int x;
        cin >> x;
        if (x > best) {
            best = x;
            pos = i;
        }
    }
    cout << best << " " << pos << "\n";
    return 0;
}
```

```input
5
3 8 -2 8 6
```

```output
8 2
```

Через строгу нерівність `>` запам’ятовується **перший** із кількох однакових максимумів. Якщо замінити її на `>=`, запам’ятається останній.

## Поки не зустрінеться нуль

Іноді кількість чисел не повідомляють, а кажуть: «послідовність закінчується числом 0». Тоді читаємо перше число до циклу, а наступне — в кінці тіла циклу:

```cpp
#include <iostream>
using namespace std;

int main() {
    int x, count = 0;
    cin >> x;
    while (x != 0) {
        if (x % 2 == 0) count++;
        cin >> x;
    }
    cout << count << "\n";
    return 0;
}
```

```input
4 7 10 3 8 0
```

```output
3
```

Сам нуль не обробляється: це лише ознака кінця.

## До кінця введення

Буває, що числа йдуть просто до кінця вхідних даних. Вираз `cin >> x` можна використати як умову: він істинний, якщо число вдалося прочитати, і хибний, коли дані закінчилися.

```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    long long sum = 0;
    while (cin >> x) {
        sum += x;
    }
    cout << sum << "\n";
    return 0;
}
```

```input
1 2 3
4 5
```

```output
15
```

> [!TIP]
> Якщо запускаєш таку програму в консолі на своєму комп’ютері, програма чекатиме нових чисел. Щоб повідомити про кінець введення, натисни <kbd>Ctrl</kbd>+<kbd>Z</kbd> і <kbd>Enter</kbd> у Windows (у Linux і macOS — <kbd>Ctrl</kbd>+<kbd>D</kbd>).

## Прапорці: «чи всі?» і «чи є хоча б один?»

Щоб перевірити, чи **всі** числа мають якусь властивість, заводять змінну-**прапорець** типу `bool`. Спершу вважаємо, що всі підходять (`true`), а щойно трапиться невідповідне число — «опускаємо прапорець» (`false`).

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool allPositive = true;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x <= 0) {
            allPositive = false;
        }
    }
    cout << (allPositive ? "YES" : "NO") << "\n";
    return 0;
}
```

```input
4
5 2 0 7
```

```output
NO
```

Для питання «чи є **хоча б одне**…» усе навпаки: спершу прапорець `false`, а знайшовши потрібне число, ставимо `true`.

> [!IMPORTANT]
> Навіть коли відповідь уже ясна, дочитуй усі числа до кінця. Інакше «зайві» числа залишаться непрочитаними, і це може зіпсувати програму, якщо далі вона читає ще щось.

## Порівняння з попереднім

Щоб порівнювати кожне число з попереднім, зберігаємо попереднє в окремій змінній `prev`. Наприклад, перевіримо, чи послідовність **строго зростає**:

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int prev;
    cin >> prev;
    bool increasing = true;
    for (int i = 1; i < n; i++) {
        int x;
        cin >> x;
        if (x <= prev) increasing = false;
        prev = x;              // поточне стає попереднім для наступного
    }
    cout << (increasing ? "YES" : "NO") << "\n";
    return 0;
}
```

```input
5
1 3 4 9 12
```

```output
YES
```

## Перевір себе

```quiz
? Чому для пошуку максимуму погано починати з `best = 0`?
- Бо 0 — не число
+ Бо якщо всі числа від’ємні, програма виведе 0
- Бо тоді цикл не запуститься
: Початкове значення має бути одним із чисел послідовності або свідомо меншим за будь-яке з них.

? Як змінити пошук номера максимуму, щоб запам’ятовувався останній із рівних максимумів?
- Замінити `>` на `<`
+ Замінити `>` на `>=`
- Нічого не змінювати
: З `>=` кожен наступний рівний максимум теж оновлює номер.

? Що означає умова `while (cin >> x)`?
+ Повторювати, поки вдається прочитати чергове число
- Повторювати, поки `x` не дорівнює нулю
- Прочитати лише одне число
: Коли дані закінчуються, `cin >> x` стає хибним, і цикл завершується.

? Перевіряємо, чи всі числа парні. Яким має бути прапорець на початку?
+ `true`
- `false`
- Байдуже
: Спершу вважаємо, що всі підходять, і опускаємо прапорець при першому непарному числі.
```

```exercise
#include <iostream>
```

```exercise
Дано `n` різних цілих чисел. Знайди друге за величиною число — те, що стало б найбільшим, якби прибрати максимум.
=== input
У першому рядку — число `n` (2 ≤ n ≤ 10⁵). У другому — `n` різних цілих чисел, кожне за модулем не більше 10⁹.
=== output
Друге за величиною число.
=== example
5
3 8 -2 10 6
---
8
=== test
2
1 2
---
1
=== test
2
2 1
---
1
=== test
4
-1 -2 -3 -4
---
-2
=== test
5
5 4 3 2 1
---
4
=== hint
Зберігай два значення: найбільше `first` і друге `second`. Нове число `x` може бути більшим за `first` — тоді старий `first` стає другим. А може бути між ними — тоді воно стає новим `second`.
=== hint
Почни з `first` і `second`, менших за будь-яке можливе число, наприклад −2·10⁹.
=== solution
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long first = -2000000000LL, second = -2000000000LL;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (x > first) {
            second = first;
            first = x;
        } else if (x > second) {
            second = x;
        }
    }
    cout << second << "\n";
    return 0;
}
```

## Коротко

- Сума і кількість — накопичувачі, що починаються з 0.
- Мінімум і максимум починай з першого числа послідовності; номер зберігай разом зі значенням.
- Послідовність до нуля: читай перше число до циклу, наступне — в кінці тіла.
- `while (cin >> x)` читає числа до кінця введення.
- Прапорець `bool` відповідає на питання «чи всі?» і «чи є хоча б одне?».
- Для порівняння з попереднім числом зберігай його в змінній `prev`.
