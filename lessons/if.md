# Умовний оператор if

Досі програми виконували всі команди підряд. Але часто треба діяти по-різному залежно від даних: якщо число від’ємне — одне, інакше — інше. Для цього існує **умовний оператор** `if`.

> [!NOTE] У цьому уроці
> - як порівнювати числа;
> - `if` і `if … else`;
> - навіщо фігурні дужки;
> - дві найчастіші помилки з `if`.

## Порівняння

Порівняння — це вираз, результатом якого є **істина** (`true`) або **хиба** (`false`).

| Запис у C++ | Значення | Приклад, що є істиною |
| --- | --- | --- |
| `a == b` | дорівнює | `5 == 5` |
| `a != b` | не дорівнює | `5 != 3` |
| `a < b` | менше | `3 < 5` |
| `a > b` | більше | `5 > 3` |
| `a <= b` | менше або дорівнює | `5 <= 5` |
| `a >= b` | більше або дорівнює | `7 >= 5` |

> [!IMPORTANT]
> Рівність перевіряють **двома** знаками: `==`. Один знак `=` — це присвоєння, і плутати їх не можна.

## `if`: виконати, якщо умова істинна

```cpp
if (умова) {
    команди, що виконуються, лише коли умова істинна
}
```

Умову пишуть у круглих дужках, а команди — у фігурних. Наприклад, програма повідомляє про мороз, лише якщо температура нижча за нуль:

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    if (t < 0) {
        cout << "Frost!" << "\n";
    }
    cout << "Temperature: " << t << "\n";
    return 0;
}
```

```input
-5
```

```output
Frost!
Temperature: -5
```

Запусти програму з введенням `12` (натисни «Змінити» і зміни число): рядок `Frost!` не з’явиться, а другий `cout` виконається в будь-якому разі — він стоїть поза фігурними дужками.

## `if … else`: або одне, або інше

Часто треба вибрати одну з двох дій. Для цього після `if` додають `else` («інакше»):

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n % 2 == 0) {
        cout << "EVEN" << "\n";
    } else {
        cout << "ODD" << "\n";
    }
    return 0;
}
```

```input
7
```

```output
ODD
```

Виконається **рівно одна** з гілок: якщо умова істинна — перша, інакше — друга.

Ще приклад — більше з двох чисел без функції `max`:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a > b) {
        cout << a << "\n";
    } else {
        cout << b << "\n";
    }
    return 0;
}
```

```input
4 9
```

```output
9
```

> [!TIP]
> У відповідях олімпіадних задач часто просять вивести `YES` або `NO`. Будь уважним до регістру: якщо в умові написано `YES`, то `Yes` чи `yes` будуть неправильною відповіддю.

## Змінюємо змінні в `if`

Усередині `if` можна не лише виводити, а й змінювати змінні. Ось як знайти модуль числа без функції `abs`:

```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;
    if (x < 0) {
        x = -x;
    }
    cout << x << "\n";
    return 0;
}
```

```input
-17
```

```output
17
```

А так можна впорядкувати два числа за зростанням:

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a > b) {
        swap(a, b);
    }
    cout << a << " " << b << "\n";
    return 0;
}
```

```input
8 3
```

```output
3 8
```

## Фігурні дужки

Якщо в гілці лише одна команда, фігурні дужки можна не писати:

```cpp
if (x < 0)
    x = -x;
```

Але без дужок до `if` належить **лише одна** наступна команда, незалежно від відступів. Дивись, що відбувається:

```cpp
#include <iostream>
using namespace std;

int main() {
    int money = 50;
    if (money > 100)
        cout << "Buy a game" << "\n";
        cout << "Buy a ball" << "\n";
    return 0;
}
```

```output
Buy a ball
```

Хоча відступи підказують, що обидві покупки залежать від умови, другий `cout` виконується завжди. Компілятор не дивиться на відступи!

> [!TIP]
> Поки вчишся, завжди пиши фігурні дужки — навіть для однієї команди. Це вбереже від помилок.

## Дві підступні помилки

### `=` замість `==`

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 3;
    if (x = 5) {
        cout << "x is five" << "\n";
    }
    return 0;
}
```

```output
x is five
```

`x = 5` — це не порівняння, а присвоєння: змінна `x` стає 5, а все, що не нуль, вважається істиною. Тому умова виконується завжди. Компілятор програму пропускає, лише іноді попереджає. Правильно: `if (x == 5)`.

### Крапка з комою після `if`

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = -10;
    if (x > 0); {
        cout << "positive" << "\n";
    }
    return 0;
}
```

```output
positive
```

Крапка з комою відразу після `if (x > 0)` — це «порожня команда». Саме вона і стала тілом `if`, а блок у фігурних дужках виконується вже незалежно від умови. Після `if (…)` крапку з комою не ставлять.

> [!CAUTION]
> Перевіряй непарність умовою `n % 2 != 0`, а не `n % 2 == 1`. Для від’ємних чисел остача від’ємна: `-7 % 2` дорівнює −1, а не 1.

## Перевір себе

```quiz
? Як правильно перевірити, що `x` дорівнює 10?
- `if (x = 10)`
+ `if (x == 10)`
- `if (x === 10)`
: Порівняння на рівність — два знаки `==`. Один знак — це присвоєння.

? Що виведе фрагмент?
| int x = 7;
| if (x > 5) {
|     cout << "A";
| } else {
|     cout << "B";
| }
+ A
- B
- AB
: 7 > 5 — істина, тому виконується перша гілка.

? Що виведе фрагмент?
| int x = 2;
| if (x > 5)
|     cout << "big ";
|     cout << "number";
- Нічого
+ `number`
- `big number`
: Без фігурних дужок до `if` належить лише перша команда. Друга виконується завжди.

? Що виведе фрагмент?
| int x = 0;
| if (x = 0) {
|     cout << "zero";
| } else {
|     cout << "not zero";
| }
- `zero`
+ `not zero`
- Помилка компіляції
: `x = 0` — присвоєння, його результат 0, а 0 вважається хибою. Ось чому `=` в умові — така підступна помилка.

? Яка умова перевіряє, що число `n` непарне, для будь-яких цілих `n`?
- `n % 2 == 1`
+ `n % 2 != 0`
- `n / 2 == 1`
: Для від’ємних непарних чисел остача дорівнює −1, тому надійніше порівнювати з нулем.
```

## Коротко

- Порівняння: `==`, `!=`, `<`, `>`, `<=`, `>=`; результат — `true` або `false`.
- `if (умова) { … }` виконує блок, лише коли умова істинна; `else { … }` — коли хибна.
- Без фігурних дужок до `if` належить лише одна команда — краще завжди писати дужки.
- Не плутай `=` (присвоєння) і `==` (порівняння); не став `;` після `if (…)`.
