# Цикл while

Цикл `for` зручний, коли наперед відомо, скільки разів повторювати дію. А якщо невідомо? Скільки цифр у числі? Скільки років треба тримати гроші в банку, щоб їх стало вдвічі більше? Для таких задач є цикл `while`.

> [!NOTE] У цьому уроці
> - як працює цикл `while`;
> - як розібрати число будь-якої довжини на цифри;
> - як перевернути число;
> - цикл `do … while`;
> - як не потрапити в нескінченний цикл.

## Як працює `while`

```cpp
while (умова) {
    тіло циклу
}
```

`while` означає «поки». Поки умова істинна, тіло виконується знову і знову. Умова перевіряється **перед** кожною ітерацією, тому якщо вона хибна від самого початку, тіло не виконається жодного разу.

Скільки разів можна поділити число навпіл, доки воно не стане меншим за 1?

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int steps = 0;
    while (n > 1) {
        n /= 2;
        steps++;
    }
    cout << steps << "\n";
    return 0;
}
```

```input
100
```

```output
6
```

100 → 50 → 25 → 12 → 6 → 3 → 1: шість ділень.

> [!IMPORTANT]
> Тіло циклу `while` обов’язково має змінювати щось, від чого залежить умова. Інакше умова залишиться істинною назавжди, і програма «зависне».

## `for` і `while` — родичі

Будь-який цикл `for` можна переписати через `while`:

```cpp
for (int i = 1; i <= 5; i++) {     int i = 1;
    cout << i;                     while (i <= 5) {
}                                      cout << i;
                                       i++;
                                   }
```

Зазвичай `for` беруть, коли відомо кількість повторень, а `while` — коли цикл триває «до якоїсь події».

## Розбір числа на цифри

У уроці про арифметику ми знайшли суму цифр тризначного числа. Тепер можемо працювати з числом будь-якої довжини. Ідея: поки число не стало нулем, відщипуємо останню цифру (`n % 10`) і відкидаємо її (`n /= 10`).

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;   // остання цифра
        sum += digit;
        n /= 10;              // відкидаємо її
    }
    cout << sum << "\n";
    return 0;
}
```

```input
4827
```

```output
21
```

Простежимо:

| `n` перед ітерацією | `digit` | `sum` після ітерації |
| --- | --- | --- |
| 4827 | 7 | 7 |
| 482 | 2 | 9 |
| 48 | 8 | 17 |
| 4 | 4 | 21 |
| 0 — цикл завершено | | |

За тією самою схемою можна порахувати кількість цифр (`count++` замість `sum += digit`), знайти найбільшу цифру чи перевірити, чи є в числі цифра 7.

## Перевернути число

Щоб записати число задом наперед, будуємо нове число: на кожному кроці «зсуваємо» його вліво (множимо на 10) і дописуємо чергову цифру справа.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    cout << reversed << "\n";
    return 0;
}
```

```input
1234
```

```output
4321
```

| `n` | `n % 10` | `reversed` |
| --- | --- | --- |
| 1234 | 4 | 4 |
| 123 | 3 | 43 |
| 12 | 2 | 432 |
| 1 | 1 | 4321 |

Число є **паліндромом**, якщо воно однаково читається в обох напрямках (наприклад, 12321). Перевірити це легко: перевернути число і порівняти з початковим. Тільки збережи початкове значення в окремій змінній — цикл змінює `n`!

## Цикл `do … while`

У цьому циклі умова перевіряється **після** тіла, тому тіло виконується хоча б один раз:

```cpp
do {
    тіло циклу
} while (умова);
```

Навіщо це потрібно? Порахуймо цифри числа звичайним `while`: для `n = 0` цикл не виконається жодного разу, і програма скаже, що в нулі 0 цифр. Але число 0 записується однією цифрою! З `do … while` усе правильно:

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    int count = 0;
    do {
        count++;
        n /= 10;
    } while (n > 0);
    cout << count << "\n";
    return 0;
}
```

```input
0
```

```output
1
```

> [!TIP]
> Завжди перевіряй програму на «незручних» даних: на нулі, на одиниці, на найбільшому можливому числі. Саме на таких тестах олімпіадні розв’язки найчастіше втрачають бали.

## Нескінченний цикл

Ось програма, яка ніколи не закінчиться, бо змінна `n` в циклі не змінюється (кнопки «Запустити» тут немає навмисно):

```cpp norun
#include <iostream>
using namespace std;

int main() {
    int n = 10;
    while (n > 0) {
        cout << n << "\n";
        // забули написати n--;
    }
    return 0;
}
```

Якщо програма раптом «зависла» — шукай цикл, умова якого ніколи не стає хибною. У Code::Blocks зупинити таку програму можна, закривши вікно консолі.

## Перевір себе

```quiz

| int x = 10;
| while (x < 5) {
|     x++;
| }
+ Жодного разу

- П’ять разів

| int n = 345, s = 0;
| while (n > 0) {
|     s += n % 10;
|     n /= 10;
| }
| cout << s;
- 345
+ 12
- 543
: Це сума цифр: 5 + 4 + 3 = 12.

? Чим `do … while` відрізняється від `while`?
- Нічим
+ Тіло `do … while` виконується хоча б один раз
- `do … while` не може бути нескінченним
: У `do … while` умова перевіряється після тіла.

? Що виведе фрагмент для `n = 120`?
| int r = 0;
| while (n > 0) { r = r * 10 + n % 10; n /= 10; }
```

```exercise
#include <iostream>
```

```exercise
    long long s, p, t;

        s += s * p / 100;
        years++;
    }
    cout << years << "\n";
    return 0;
}
```

## Коротко

- `while (умова) { … }` повторює тіло, поки умова істинна; умова перевіряється перед кожною ітерацією.
- `do { … } while (умова);` виконує тіло хоча б один раз.
- Цифри числа: `n % 10` — остання цифра, `n /= 10` — відкинути її; повторюй, поки `n > 0`.
- Перевернути число: `r = r * 10 + n % 10`.
- Тіло циклу має змінювати те, від чого залежить умова, інакше цикл нескінченний.
