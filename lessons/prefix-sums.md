# Префіксні суми

Задача: дано масив із `n` чисел і `q` запитів «яка сума елементів з `l`-го по `r`-й?». Якщо на кожен запит рахувати суму циклом, вийде до n · q дій — для `n = q = 10⁵` це 10¹⁰, задовго. Префіксні суми дозволяють відповідати на кожен запит **за одну дію**.

> [!NOTE] У цьому уроці
> - що таке префіксні суми і як їх обчислити;
> - сума будь-якого відрізка за O(1);
> - префіксні суми для підрахунку кількості;
> - двовимірні префіксні суми;
> - різницевий масив: додавання на відрізку.

## Ідея

**Префікс** — це початок масиву. Префіксна сума `p[i]` — сума перших `i` елементів:

`p[i] = a[1] + a[2] + … + a[i]`, а `p[0] = 0`.

Тут зручно нумерувати елементи з одиниці. Обчислюються всі префіксні суми одним проходом: кожна наступна дорівнює попередній плюс черговий елемент:

`p[i] = p[i − 1] + a[i]`.

| i | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| a[i] | — | 3 | 1 | 4 | 1 | 5 |
| p[i] | 0 | 3 | 4 | 8 | 9 | 14 |

Тепер сума з `l`-го по `r`-й елемент — це «сума перших `r`» мінус «сума перших `l − 1`»:

**sum(l, r) = p[r] − p[l − 1]**.

Наприклад, сума з 2-го по 4-й: p[4] − p[1] = 9 − 3 = 6 (справді, 1 + 4 + 1 = 6).

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, q;
    cin >> n >> q;
    vector<long long> p(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        p[i] = p[i - 1] + x;
    }
    for (int k = 0; k < q; k++) {
        int l, r;
        cin >> l >> r;
        cout << p[r] - p[l - 1] << "\n";
    }
    return 0;
}
```

```input
5 3
3 1 4 1 5
2 4
1 5
3 3
```

```output
6
14
4
```

Підготовка — O(n), кожен запит — O(1). Разом O(n + q) замість O(n · q).

> [!TIP]
> Саме тому масив `p` має `n + 1` елемент і `p[0] = 0`: тоді формула `p[r] − p[l − 1]` працює і для `l = 1` без окремої перевірки.

## Префіксні суми для підрахунку

Префіксні суми рахують не лише суми, а й **кількості**. Щоб відповідати на запити «скільки парних чисел на відрізку», будуємо префіксні суми для масиву з нулів і одиниць: 1 — якщо число парне, 0 — якщо ні.

```cpp
p[i] = p[i - 1] + (a[i] % 2 == 0 ? 1 : 0);
```

Так само рахують кількість певних символів у частині рядка, кількість днів з морозом у проміжку дат тощо.

## Двовимірні префіксні суми

Для таблиці `P[i][j]` — сума прямокутника з кутами (1, 1) і (i, j). Обчислюється так:

`P[i][j] = a[i][j] + P[i − 1][j] + P[i][j − 1] − P[i − 1][j − 1]`

(прямокутник згори і прямокутник зліва перекриваються, тому їхню спільну частину віднімаємо один раз).

Сума прямокутника з кутами (r1, c1) і (r2, c2):

`P[r2][c2] − P[r1 − 1][c2] − P[r2][c1 − 1] + P[r1 − 1][c1 − 1]`.

## Різницевий масив

Обернена задача: багато разів «додай `x` до всіх елементів з `l` по `r`», а в кінці виведи масив. Хитрість: заведемо масив `d` і для кожної операції змінимо лише **два** елементи:

```cpp
d[l] += x;
d[r + 1] -= x;
```

Наприкінці префіксні суми масиву `d` дадуть, скільки додано до кожного елемента. Кожна операція — O(1), відновлення — O(n).

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<long long> d(n + 2, 0);
    for (int k = 0; k < m; k++) {
        int l, r;
        long long x;
        cin >> l >> r >> x;
        d[l] += x;
        d[r + 1] -= x;
    }
    long long cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += d[i];
        cout << cur << " ";
    }
    cout << "\n";
    return 0;
}
```

```input
5 2
1 3 10
2 5 1
```

```output
10 11 11 1 1
```

## Перевір себе

```quiz
? Масив: 2, 7, 1, 8, 2. Чому дорівнює `p[3]` (сума перших трьох)?
- 1
+ 10
- 18
: 2 + 7 + 1 = 10.

? Як обчислити суму елементів з `l`-го по `r`-й через префіксні суми?
- `p[r] - p[l]`
+ `p[r] - p[l - 1]`
- `p[r] + p[l - 1]`
: Від суми перших `r` елементів віднімаємо суму перших `l − 1` — тих, що лежать перед відрізком.

? Яка складність відповіді на `q` запитів суми на відрізку з префіксними сумами?
+ O(n + q)
- O(n · q)
- O(q²)
: O(n) на побудову і O(1) на кожен запит.

? Навіщо в масиві префіксних сум елемент `p[0] = 0`?
- Щоб масив мав парну довжину
+ Щоб формула працювала і для відрізків, що починаються з першого елемента
- Він не потрібен
: Для `l = 1` формула дає `p[r] − p[0] = p[r]`.
```

    int n;

    vector<long long> p(n + 1, 0);

        cin >> x;
        p[i] = p[i - 1] + x;

        if (p[i - 1] == p[n] - p[i]) {
            answer = i;
            break;
        }
    }
    cout << answer << "\n";
    return 0;
}

Побудуй `P[i][j] = a[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1]`, а відповідь на запит — за формулою з уроку.
=== solution
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m, q;
    cin >> n >> m >> q;
    vector<vector<long long>> P(n + 1, vector<long long>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            long long x;
            cin >> x;
            P[i][j] = x + P[i - 1][j] + P[i][j - 1] - P[i - 1][j - 1];
        }
    while (q--) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        cout << P[r2][c2] - P[r1 - 1][c2] - P[r2][c1 - 1] + P[r1 - 1][c1 - 1] << "\n";
    }
    return 0;
}

## Коротко

- `p[0] = 0`, `p[i] = p[i − 1] + a[i]`; сума відрізка `[l, r]` — `p[r] − p[l − 1]`.
- Побудова O(n), кожен запит O(1).
- Префіксні суми рахують і кількості — для масиву з нулів і одиниць.
- Двовимірні префіксні суми — для сум прямокутників.
- Різницевий масив (`d[l] += x`, `d[r + 1] -= x`) — для багатьох додавань на відрізках.
