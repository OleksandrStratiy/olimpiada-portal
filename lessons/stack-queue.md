# Стек і черга

Буває важливо не лише **що** зберігати, а й **у якому порядку** забирати. Стос тарілок: беремо верхню — ту, яку поклали останньою. Черга в магазині: першим обслуговують того, хто прийшов першим. У C++ є готові контейнери для обох випадків — і ще для одного, «черги з пріоритетом», де першим обслуговують найважливішого.

> [!NOTE] У цьому уроці
> - стек `stack`: останнім прийшов — першим вийшов;
> - перевірка правильності дужок;
> - черга `queue`: першим прийшов — першим вийшов;
> - двостороння черга `deque`;
> - черга з пріоритетом `priority_queue`.

## Стек

**Стек** (`stack`, бібліотека `stack`) — це «стос»: додавати і забирати елементи можна лише згори. Останній покладений елемент забирається першим.

| Команда | Що робить |
| --- | --- |
| `st.push(x)` | кладе `x` нагору |
| `st.top()` | верхній елемент (не забираючи його) |
| `st.pop()` | забирає верхній елемент |
| `st.empty()` | чи порожній стек |
| `st.size()` | кількість елементів |

```cpp
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> st;
    st.push(1);
    st.push(2);
    st.push(3);
    while (!st.empty()) {
        cout << st.top() << " ";
        st.pop();
    }
    cout << "\n";
    return 0;
}
```

```output
3 2 1
```

Числа вийшли у зворотному порядку. Стек — природний інструмент для всього, що треба «скасовувати» чи обробляти у зворотному порядку: кнопка «Скасувати» в редакторі, повернення з рекурсивних викликів, вкладені дужки.

> [!CAUTION]
> Перш ніж викликати `top()` чи `pop()`, переконайся, що стек не порожній. Звертання до верхнього елемента порожнього стеку — помилка, через яку програма може аварійно зупинитися.

## Задача про дужки

Дано рядок із дужок `()[]{}`. Чи правильно вони розставлені? Наприклад, `([]{()})` — правильно, а `([)]` і `((` — ні.

Ідея: відкривні дужки кладемо в стек. Коли трапляється закривна, на вершині стеку має лежати **відповідна** відкривна — забираємо її. Наприкінці стек має бути порожнім.

```cpp
#include <iostream>
#include <stack>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    stack<char> st;
    bool ok = true;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty()) { ok = false; break; }
            char open = st.top();
            st.pop();
            if ((c == ')' && open != '(') || (c == ']' && open != '[') || (c == '}' && open != '{')) {
                ok = false;
                break;
            }
        }
    }
    if (!st.empty()) ok = false;
    cout << (ok ? "YES" : "NO") << "\n";
    return 0;
}
```

```input
([]{()})
```

```output
YES
```

## Черга

**Черга** (`queue`, бібліотека `queue`) — як черга в магазині: нові елементи стають у кінець, а забираються з початку.

| Команда | Що робить |
| --- | --- |
| `q.push(x)` | ставить `x` у кінець черги |
| `q.front()` | перший елемент |
| `q.back()` | останній елемент |
| `q.pop()` | забирає перший елемент |
| `q.empty()`, `q.size()` | як у стеку |

Класична задача — **лічилка**. `n` дітей стоять по колу і рахують до `k`; той, на кому закінчилася лічба, виходить, а наступна лічба починається з наступної дитини. У якому порядку діти виходять із кола?

Коло зручно моделювати чергою: «пропустити» дитину — забрати її з початку і поставити в кінець.

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    queue<int> q;
    for (int i = 1; i <= n; i++) q.push(i);
    while (!q.empty()) {
        for (int i = 1; i < k; i++) {   // k − 1 дітей переходять у кінець
            q.push(q.front());
            q.pop();
        }
        cout << q.front() << " ";       // k-та дитина виходить
        q.pop();
    }
    cout << "\n";
    return 0;
}
```

```input
5 2
```

```output
2 4 1 5 3
```

Черга ще знадобиться нам в уроці про графи: на ній побудовано пошук найкоротшого шляху.

## Двостороння черга `deque`

`deque` (бібліотека `deque`) дозволяє додавати і забирати елементи з **обох** кінців: `push_front`, `push_back`, `pop_front`, `pop_back`, `front`, `back`. А ще до її елементів можна звертатися за індексом, як до масиву: `d[i]`.

## Черга з пріоритетом

`priority_queue` (бібліотека `queue`) завжди видає **найбільший** елемент, незалежно від порядку додавання. Як у лікарні: першим приймають того, кому найгірше.

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    priority_queue<int> pq;
    pq.push(3);
    pq.push(10);
    pq.push(1);
    pq.push(7);
    while (!pq.empty()) {
        cout << pq.top() << " ";
        pq.pop();
    }
    cout << "\n";
    return 0;
}
```

```output
10 7 3 1
```

Щоб першим виходив **найменший** елемент, чергу оголошують так:

```cpp
priority_queue<int, vector<int>, greater<int>> pq;
```

Додавання і вилучення працюють за ≈ log n кроків. Це дозволяє розв’язувати задачі, де треба багато разів брати найменший (чи найбільший) елемент із набору, що змінюється.

**Приклад.** Є мотузки різної довжини. За один раз можна зв’язати дві мотузки в одну; це коштує стільки, скільки сумарна довжина двох мотузок. Як зв’язати всі мотузки в одну найдешевше? Виявляється, щоразу вигідно зв’язувати **дві найкоротші** мотузки. З чергою з пріоритетом це кілька рядків:

```cpp
#include <iostream>
#include <queue>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    priority_queue<long long, vector<long long>, greater<long long>> pq;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        pq.push(x);
    }
    long long total = 0;
    while (pq.size() > 1) {
        long long a = pq.top(); pq.pop();
        long long b = pq.top(); pq.pop();
        total += a + b;
        pq.push(a + b);
    }
    cout << total << "\n";
    return 0;
}
```

```input
4
4 3 2 6
```

```output
29
```

Зв’язуємо 2 і 3 (вартість 5), потім 4 і 5 (вартість 9), потім 6 і 9 (вартість 15): разом 29.

## Перевір себе

```quiz

- 2
- 3
: Спершу забрали 3, потім 2 — залишилася 1.

- 1
+ 2
- 3
: З черги першим виходить той, хто прийшов першим, тобто 1. Тепер перша — 2.

? Що поверне `top()` у `priority_queue<int>`, куди додали 5, 9, 2?
- 5
+ 9
- 2
: Звичайна черга з пріоритетом видає найбільший елемент.

? Чи правильно розставлено дужки `([)]`?
- Так
+ Ні
: Перша закривна дужка `)`, а на вершині стеку лежить `[` — пара не збігається.
```

```exercise
=== hint
Для елемента `a[i]` зніми зі стеку всі значення, що не більші за `a[i]`: вони вже ніколи не стануть відповіддю для елементів лівіше. Тепер вершина стеку (якщо він не порожній) — відповідь для `a[i]`. Потім поклади `a[i]` у стек.
=== solution
#include <iostream>
#include <vector>
#include <stack>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n), ans(n);
    for (int &x : a) cin >> x;
    stack<int> st;
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && st.top() <= a[i]) st.pop();
        ans[i] = st.empty() ? -1 : st.top();
        st.push(a[i]);
    }
    for (int x : ans) cout << x << " ";
    cout << "\n";
    return 0;
}
```

## Коротко

- `stack` — останнім прийшов, першим вийшов: `push`, `top`, `pop`, `empty`.
- Стек перевіряє правильність дужок і обробляє дані у зворотному порядку.
- `queue` — першим прийшов, першим вийшов: `push`, `front`, `pop`; лічилка і обхід у ширину.
- `deque` — додавання і вилучення з обох кінців.
- `priority_queue` видає найбільший елемент; з `greater` — найменший.
