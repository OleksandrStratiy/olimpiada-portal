# Алгоритми з масивами

Масив — основний інструмент олімпіадника. У цьому уроці розберемо класичні дії з масивами: пошук, розворот, зсув, видалення і, мабуть, найкорисніший прийом — масив лічильників.

> [!NOTE] У цьому уроці
> - лінійний пошук і підрахунок;
> - розворот масиву на місці;
> - циклічний зсув;
> - видалення і вставка елемента;
> - масив лічильників: найчастіше значення, кількість різних чисел.

## Пошук елемента

Щоб знайти, де в масиві стоїть число `x`, переглядаємо елементи по черзі. Це називається **лінійним пошуком**.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, x;
    cin >> n >> x;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int pos = -1;                      // -1 означає «не знайдено»
    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            pos = i;
            break;                     // знайшли перше входження
        }
    }
    cout << pos << "\n";
    return 0;
}
```

```input
6 4
7 4 9 4 1 3
```

```output
1
```

Тут масив уже прочитано повністю, тому `break` безпечний. Якщо потрібно **останнє** входження — прибери `break` (або йди з кінця масиву). Щоб порахувати, **скільки разів** трапляється `x`, заміни запам’ятовування позиції на лічильник.

## Розворот на місці

Щоб переставити елементи у зворотному порядку без другого масиву, міняємо місцями перший і останній елементи, другий і передостанній, і так до середини:

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n / 2; i++) {
        swap(a[i], a[n - 1 - i]);
    }
    for (int x : a) cout << x << " ";
    cout << "\n";
    return 0;
}
```

```input
5
1 2 3 4 5
```

```output
5 4 3 2 1
```

Елементу з індексом `i` відповідає «дзеркальний» елемент з індексом `n − 1 − i`. Цикл іде лише до середини (`i < n / 2`): якби ми дійшли до кінця, кожну пару обміняли б двічі, і масив повернувся б до початкового вигляду.

> [!TIP]
> У бібліотеці `algorithm` є готова функція: `reverse(a.begin(), a.end());`. Але вміти написати розворот самому теж важливо — ця ідея трапляється в багатьох задачах.

## Циклічний зсув

**Циклічний зсув вправо на 1**: кожен елемент переходить на одну позицію праворуч, а останній стає першим. Наприклад, `1 2 3 4 5` → `5 1 2 3 4`.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int last = a[n - 1];               // запам’ятовуємо останній
    for (int i = n - 1; i > 0; i--) {
        a[i] = a[i - 1];               // зсуваємо, починаючи з кінця
    }
    a[0] = last;
    for (int x : a) cout << x << " ";
    cout << "\n";
    return 0;
}
```

```input
5
1 2 3 4 5
```

```output
5 1 2 3 4
```

Чому цикл іде з кінця? Якби ми почали з початку (`a[1] = a[0]`, потім `a[2] = a[1]`…), то значення `a[0]` скопіювалося б в усі елементи.

Для зсуву на `k` позицій зручніше створити новий масив: елемент з індексом `i` переходить на позицію `(i + k) % n`. Остача «загортає» позиції, що вийшли за кінець, на початок.

## Видалення і вставка

Видалити елемент з індексом `k` — означає зсунути всі наступні елементи на одну позицію вліво і зменшити масив:

```cpp
for (int i = k; i + 1 < n; i++) a[i] = a[i + 1];
a.pop_back();
```

У `vector` є і готові команди: `a.erase(a.begin() + k)` видаляє елемент з індексом `k`, а `a.insert(a.begin() + k, x)` вставляє `x` на позицію `k`. Але пам’ятай: вони теж зсувають усі наступні елементи, тому для великих масивів це повільно.

## Масив лічильників

Дуже потужний прийом. Нехай числа невеликі — наприклад, оцінки від 1 до 12. Заведемо масив `cnt`, де `cnt[v]` — скільки разів трапилося значення `v`. Кожне прочитане число просто збільшує свій лічильник:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> cnt(13, 0);            // індекси 0..12, використовуємо 1..12
    for (int i = 0; i < n; i++) {
        int mark;
        cin >> mark;
        cnt[mark]++;
    }
    for (int v = 1; v <= 12; v++) {
        if (cnt[v] > 0) cout << v << ": " << cnt[v] << "\n";
    }
    return 0;
}
```

```input
8
10 7 12 10 9 7 10 4
```

```output
4: 1
7: 2
9: 1
10: 3
12: 1
```

За допомогою масиву лічильників легко:

- знайти **найчастіше** значення — індекс найбільшого `cnt[v]`;
- порахувати **кількість різних** значень — скільки `cnt[v]` більші за нуль;
- перевірити, чи є **повтори** — чи є `cnt[v] > 1`;
- вивести числа **за зростанням** — пройти `v` від найменшого значення до найбільшого і вивести кожне `v` рівно `cnt[v]` разів (це **сортування підрахунком**).

> [!WARNING]
> Масив лічильників підходить, лише коли значення невеликі: розмір `cnt` дорівнює найбільшому можливому значенню. Для чисел до 10⁶ — нормально, а для чисел до 10⁹ масив не вміститься в пам’ять. Для таких випадків є інші інструменти (сортування, `map`), про них — у наступних розділах.

+ Усі елементи стануть рівними `a[0]`

=== solution
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> cnt(1000001, 0);
    int distinct = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (cnt[x] == 0) distinct++;
        cnt[x]++;
    }
    cout << distinct << "\n";
    return 0;
}

## Коротко

- Лінійний пошук переглядає елементи по черзі; −1 або 0 — зручна позначка «не знайдено».
- Розворот на місці: обмін `a[i]` і `a[n − 1 − i]` до середини масиву.
- Зсув вправо — копіювання з кінця; зсув на `k` — новий масив і позиція `(i + k) % n`.
- `erase` і `insert` зсувають елементи, тож працюють повільно для великих масивів.
- Масив лічильників `cnt[v]++` розв’язує задачі про частоти, повтори і кількість різних значень, коли значення невеликі.
