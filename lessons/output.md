# Виведення на екран

Ми вже вміємо виводити текст. Але комп’ютер створено, щоб рахувати! У цьому уроці навчимося виводити числа, обчислювати вирази і акуратно розставляти пробіли та переходи на новий рядок.

> [!NOTE] У цьому уроці
> - чим число відрізняється від тексту;
> - як обчислювати вирази просто в `cout`;
> - як вивести кілька значень через пробіл;
> - як вивести лапки, зворотну косу риску й інші особливі символи.

## Числа і текст

Числа в C++ пишуть **без лапок**. Порівняй дві програми:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "2 + 3" << "\n";
    cout << 2 + 3 << "\n";
    return 0;
}
```

```output
2 + 3
5
```

У першому рядку `"2 + 3"` у лапках — це просто **текст** з п’яти символів, і він виводиться як є. У другому рядку `2 + 3` без лапок — це **вираз**: комп’ютер спершу обчислює його, а потім виводить результат.

> [!IMPORTANT]
> Лапки означають «виведи буквально, як написано». Без лапок комп’ютер вважає написане числом, виразом або назвою чогось.

## Арифметичні дії

У виразах можна використовувати звичні дії:

| Дія | Знак у C++ | Приклад | Результат |
| --- | --- | --- | --- |
| додавання | `+` | `7 + 2` | 9 |
| віднімання | `-` | `7 - 2` | 5 |
| множення | `*` | `7 * 2` | 14 |
| ділення | `/` | `8 / 2` | 4 |

Зверни увагу: множення позначається зірочкою `*`, а не крапкою чи хрестиком.

Порядок дій такий самий, як у математиці: спершу множення і ділення, потім додавання і віднімання. Щоб змінити порядок, використовують круглі дужки:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 2 + 3 * 4 << "\n";
    cout << (2 + 3) * 4 << "\n";
    cout << 100 - 10 - 5 << "\n";
    cout << 2 * (3 + 4) * 5 << "\n";
    return 0;
}
```

```output
14
20
85
70
```

> [!WARNING] Ділення цілих чисел
> Спробуй вивести `7 / 2`. Результат здивує: вийде `3`, а не `3.5`. Коли ділять ціле число на ціле, C++ відкидає дробову частину. Це не помилка, а дуже корисна властивість — детально розберемо її в уроці «Арифметика і ділення націло».

## Кілька значень в одному рядку

В одній команді `cout` можна вивести скільки завгодно значень — кожне через свою стрілку `<<`:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 1 << 2 << 3 << "\n";
    cout << 1 << " " << 2 << " " << 3 << "\n";
    return 0;
}
```

```output
123
1 2 3
```

Числа «злиплися» в `123`, бо `cout` не ставить пробіли сам. Між значеннями треба явно вивести пробіл `" "`.

Текст і числа можна змішувати:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "6 * 7 = " << 6 * 7 << "\n";
    cout << "In a week: " << 7 * 24 << " hours" << "\n";
    return 0;
}
```

```output
6 * 7 = 42
In a week: 168 hours
```

Тут `"6 * 7 = "` — текст (він у лапках, тому не обчислюється), а `6 * 7` — вираз, який перетворюється на 42.

> [!TIP]
> Довгу команду можна розбити на кілька рядків — компілятор зважає лише на `;`:
> ```cpp
> cout << "Monday" << " "
>      << "Tuesday" << "\n";
> ```

## Особливі символи

Як вивести самі лапки, якщо лапки позначають початок і кінець тексту? Для цього є **екрановані символи** — пари, що починаються зі зворотної косої риски `\`:

| Запис | Що виводить |
| --- | --- |
| `\n` | перехід на новий рядок |
| `\"` | подвійні лапки `"` |
| `\\` | зворотну косу риску `\` |
| `\t` | табуляцію (великий відступ) |

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "She said: \"Hello!\"\n";
    cout << "Folder: C:\\Games\n";
    return 0;
}
```

```output
She said: "Hello!"
Folder: C:\Games
```

> [!CAUTION]
> Якщо всередині тексту написати просто `"`, компілятор вирішить, що текст закінчився, і повідомить про помилку. А одна `\` у тексті «з’їдає» наступний символ. Тому в малюнках із символів кожну `\` пишуть двічі: `\\`.

## Перевір себе

```quiz
? Що виведе команда?
| cout << "5 + 5";
+ `5 + 5`
- `10`
- `"5 + 5"`
: Текст у лапках виводиться буквально, без обчислень, а самі лапки не виводяться.

? Що виведе команда?
| cout << 5 + 5;
- `5 + 5`
+ `10`
- `55`
: Без лапок це вираз, тому виводиться результат обчислення.

? Що виведе команда?
| cout << 2 + 3 * 4;
- `20`
+ `14`
- `2 + 12`
: Спершу множення: 3 · 4 = 12, потім додавання: 2 + 12 = 14.

? Що виведе команда?
| cout << 1 << 2 << 3;
+ `123`
- `1 2 3`
- `6`
: `cout` не додає пробілів між значеннями, тому цифри йдуть підряд.

? Як вивести на екран подвійні лапки?
- `cout << """;`
+ `cout << "\"";`
- `cout << "/"";`
: Лапки всередині тексту записують як `\"`.
```

## Коротко

- Числа і вирази пишуть без лапок — тоді комп’ютер обчислює результат.
- Текст у лапках виводиться буквально.
- Дії: `+`, `-`, `*`, `/`; порядок дій як у математиці, дужки змінюють порядок.
- `cout` не додає пробілів: між значеннями виводь `" "`.
- Особливі символи: `\n` — новий рядок, `\"` — лапки, `\\` — зворотна коса риска.
