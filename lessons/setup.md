# Де писати і запускати код

Щоб програма запрацювала, її треба десь написати, скомпілювати і запустити. Є три способи, і всі вони нам знадобляться: просто на цьому сайті, в онлайн-компіляторі й у середовищі розробки на комп’ютері.

> [!NOTE] У цьому уроці
> - як запускати код просто на сторінках курсу;
> - як користуватися онлайн-компілятором;
> - як встановити Code::Blocks і запустити в ньому програму;
> - як набирати код на клавіатурі і як називаються «програмістські» символи.

## Спосіб 1. Просто на цьому сайті

Під кожною повною програмою в уроках є кнопки:

- **Копіювати** — скопіювати код, щоб вставити його деінде;
- **Змінити** — код стає редагованим: можна змінювати його й експериментувати; кнопка «Скинути» повертає початковий варіант;
- **Запустити** — програма компілюється і виконується, а під кодом з’являється її виведення.

У задачах є редактор і дві кнопки: **«Перевірити»** запускає твою програму на всіх тестах задачі, а **«Запустити»** — один раз із введенням, яке ти вкажеш сам.

Спробуй: натисни «Змінити», заміни слово `world` своїм ім’ям латиницею і натисни «Запустити».

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
```

```output
Hello, world!
```

> [!NOTE]
> Код компілюється не у твоєму браузері, а на сервері відкритого сервісу Compiler Explorer (godbolt.org). Тому для запуску потрібен інтернет. Твій код зберігається лише в цьому браузері.

## Спосіб 2. Онлайн-компілятор

Якщо хочеться написати програму з нуля, не відкриваючи уроки, зручно скористатися онлайн-компілятором, наприклад [OnlineGDB](https://www.onlinegdb.com/online_c++_compiler):

1. Відкрий сайт і переконайся, що праворуч угорі в списку **Language** вибрано C++ (краще C++17).
2. Напиши або встав код у великому полі.
3. Натисни зелену кнопку **Run**.
4. Внизу з’явиться вікно програми. Якщо програма чекає на введення, клацни в цьому вікні, набери дані й натисни <kbd>Enter</kbd>.

## Спосіб 3. Code::Blocks на своєму комп’ютері

На олімпіаді інтернету немає, тому треба вміти працювати в **середовищі розробки** — програмі, в якій пишуть, компілюють і запускають код. У школах і на олімпіадах найчастіше трапляються Code::Blocks, Dev-C++ і Visual Studio Code. Почнемо з Code::Blocks: він безкоштовний і вже має всередині компілятор.

### Встановлення

1. Зайди на сайт [codeblocks.org](https://www.codeblocks.org/downloads/binaries/), розділ **Downloads → Binary release**.
2. Для Windows завантаж файл, у назві якого є **mingw-setup** (наприклад, `codeblocks-...mingw-setup.exe`). Слово «mingw» означає, що разом із середовищем встановиться компілятор.
3. Запусти файл і встанови програму, погоджуючись з усіма пропозиціями.

### Перша програма в Code::Blocks

1. Меню **File → New → Empty file** — з’явиться порожній файл.
2. Одразу збережи його: **File → Save file as**, назва `main.cpp`. Розширення `.cpp` обов’язкове — так Code::Blocks зрозуміє, що це програма на C++, і почне підсвічувати команди.
3. Набери програму.
4. Натисни <kbd>F9</kbd> (**Build → Build and run**) — програма скомпілюється і запуститься.
5. Відкриється чорне вікно — **консоль**. Якщо програма читає дані, набери їх у цьому вікні й натисни <kbd>Enter</kbd>. Після завершення побачиш рядок `Process returned 0` — це означає, що програма завершилася без помилок.

> [!TIP]
> Увімкни сучасний стандарт мови: **Settings → Compiler**, вкладка **Compiler Flags**, постав позначку біля пункту з `-std=c++17`. Тоді працюватимуть усі приклади з курсу.

### Інші середовища

- **Dev-C++** — дуже простий, компілятор уже всередині. Запуск — клавіша <kbd>F11</kbd>.
- **Visual Studio Code** — сучасний редактор, яким користуються професіонали. Але компілятор до нього треба встановлювати окремо, тому для початку він складніший.

Не має значення, де ти пишеш код: сама програма на C++ скрізь однакова. Але перед олімпіадою дізнайся, яке середовище буде на комп’ютерах, і потренуйся саме в ньому.

> [!WARNING] Українські літери в консолі
> Якщо програма виводить українські літери, у консолі Windows замість них можуть з’явитися дивні символи. Це не помилка в програмі, а особливість кодування консолі. На олімпіадах виводять числа й латинські слова, тому й у прикладах курсу ми пишемо текст латиницею.

## Як набирати код

Код набирають в **англійській розкладці** клавіатури. Команди C++ — це англійські слова, а лапки, дужки й інші символи мають бути саме «програмістськими». Українська літера чи друкарські лапки «ось такі» в коді — це помилка компіляції.

Ось символи, які трапляються в кожній програмі:

| Символ | Назва | Як набрати |
| --- | --- | --- |
| `;` | крапка з комою | клавіша праворуч від <kbd>L</kbd> |
| `{` `}` | фігурні дужки | <kbd>Shift</kbd> + клавіші праворуч від <kbd>P</kbd> |
| `(` `)` | круглі дужки | <kbd>Shift</kbd> + <kbd>9</kbd>, <kbd>Shift</kbd> + <kbd>0</kbd> |
| `[` `]` | квадратні дужки | клавіші праворуч від <kbd>P</kbd> |
| `<` `>` | кутові дужки (знаки «менше» і «більше») | <kbd>Shift</kbd> + клавіші праворуч від <kbd>M</kbd> |
| `"` | подвійні лапки | <kbd>Shift</kbd> + клавіша праворуч від <kbd>;</kbd> |
| `'` | одинарні лапки (апостроф) | клавіша праворуч від <kbd>;</kbd> |
| `#` | решітка | <kbd>Shift</kbd> + <kbd>3</kbd> |
| `_` | підкреслення | <kbd>Shift</kbd> + <kbd>-</kbd> |

> [!TIP]
> Відступи на початку рядків роблять клавішею <kbd>Tab</kbd> або чотирма пробілами. Комп’ютеру вони не потрібні, а людині дуже допомагають бачити, що всередині чого.

## Практика

```exercise
id: change-text
title: Зміни текст
level: 1
=== statement
У редакторі — знайома програма. Зміни її так, щоб вона виводила рядок `C++ is cool!` (саме так, з тими самими великими й малими літерами, пробілами і знаком оклику).

Натисни «Запустити», щоб подивитися на результат, а потім — «Перевірити».
=== example

C++ is cool!

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
=== hint
Змінювати потрібно лише текст між подвійними лапками.
=== solution
#include <iostream>
using namespace std;

int main() {
    cout << "C++ is cool!" << endl;
    return 0;
}
```

## Коротко

- Код можна запускати просто на сайті, в онлайн-компіляторі або в середовищі розробки на комп’ютері.
- Code::Blocks — безкоштовне середовище з компілятором усередині; запуск програми — клавіша <kbd>F9</kbd>.
- Код набирають в англійській розкладці; кожна дужка й лапка має значення.
