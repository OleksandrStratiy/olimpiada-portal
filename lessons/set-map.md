# Множини і словники: set і map

Масив добрий, коли елементи пронумеровано по порядку. А як швидко дізнатися, чи траплялося вже число 7 384 501? Або порахувати, скільки разів зустрічається кожне слово в тексті? Для цього є контейнери `set` (множина) і `map` (словник).

> [!NOTE] У цьому уроці
> - множина `set`: додавання, перевірка, видалення, перебір у порядку зростання;
> - `multiset` — множина з повторами;
> - словник `map`: ключ → значення, підрахунок частот;
> - як розв’язати задачу «дві суми» за один прохід.

## Множина `set`

`set` зберігає **різні** значення в **порядку зростання**. Повторне додавання того самого значення нічого не змінює.

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s;
    s.insert(5);
    s.insert(1);
    s.insert(5);          // 5 уже є — нічого не зміниться
    s.insert(3);
    cout << s.size() << "\n";
    for (int x : s) cout << x << " ";
    cout << "\n";
    cout << s.count(3) << " " << s.count(4) << "\n";
    s.erase(3);
    cout << s.count(3) << "\n";
    return 0;
}
```

```output
3
1 3 5
1 0
0
```

| Команда | Що робить |
| --- | --- |
| `s.insert(x)` | додає `x` (якщо його ще немає) |
| `s.count(x)` | 1, якщо `x` є в множині, і 0 — якщо немає |
| `s.erase(x)` | видаляє `x` |
| `s.size()` | кількість елементів |
| `*s.begin()` | найменший елемент |
| `*s.rbegin()` | найбільший елемент |

Головне — **швидкість**: усі ці дії виконуються приблизно за log₂ n кроків, навіть якщо в множині мільйон чисел (це близько 20 кроків). Перевірка «чи є число в масиві» потребувала б перегляду всього масиву.

Кількість різних чисел тепер рахується в одну дію: додай усі числа в `set` і візьми `size()`.

> [!TIP]
> Хочеш тримати повтори, але в порядку зростання — використовуй `multiset`. Тоді `count(x)` поверне кількість входжень `x`. Обережно: `ms.erase(x)` видаляє **всі** копії `x`, а щоб видалити одну, пишуть `ms.erase(ms.find(x))`.

## Словник `map`

`map<K, V>` зберігає пари **ключ → значення**: за ключем можна швидко знайти значення. Як у справжньому словнику: за словом знаходимо переклад. Ключі зберігаються в порядку зростання і не повторюються.

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> age;
    age["Olena"] = 13;
    age["Petro"] = 14;
    age["Olena"] = 14;              // значення за ключем перезаписується
    cout << age["Olena"] << "\n";
    cout << age.size() << "\n";
    for (auto p : age) cout << p.first << " " << p.second << "\n";
    return 0;
}
```

```output
14
2
Olena 14
Petro 14
```

Перебираючи `map`, ми отримуємо пари: `p.first` — ключ, `p.second` — значення.

## Підрахунок частот

Найчастіше `map` використовують як «розумний» масив лічильників — для будь-яких значень, хоч слів, хоч чисел до 10¹⁸:

```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, int> cnt;
    string w;
    while (cin >> w) cnt[w]++;
    for (auto p : cnt) cout << p.first << " " << p.second << "\n";
    return 0;
}
```

```input
to be or not to be
```

```output
be 2
not 1
or 1
to 2
```

Як працює `cnt[w]++`? Якщо слова `w` ще немає в словнику, звертання `cnt[w]` **створює** його зі значенням 0, а потім `++` перетворює 0 на 1.

> [!WARNING]
> Через це звертання `m[key]` до відсутнього ключа додає його в словник. Щоб лише **перевірити**, чи є ключ, використовуй `m.count(key)`, а не `m[key] != 0`.

## Задача «дві суми»

Дано масив і число `k`. Чи є два елементи, сума яких дорівнює `k`? Перебір усіх пар — це n² дій. А з множиною вистачить одного проходу: для кожного `x` перевіряємо, чи траплялося раніше число `k − x`.

```cpp
#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    set<long long> seen;
    bool found = false;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (seen.count(k - x)) found = true;
        seen.insert(x);
    }
    cout << (found ? "YES" : "NO") << "\n";
    return 0;
}
```

```input
5 10
3 8 4 2 9
```

```output
YES
```

(8 + 2 = 10.) Зверни увагу: число додаємо в множину **після** перевірки — так елемент не утворить пару сам із собою.

> [!NOTE] `unordered_set` і `unordered_map`
> Існують також `unordered_set` і `unordered_map` (однойменні бібліотеки). Вони не тримають елементи впорядкованими, зате в середньому працюють ще швидше. Якщо порядок не потрібен, ними можна користуватися так само.

## Перевір себе

```quiz
? Що виведе фрагмент?
| set<int> s;
| s.insert(4); s.insert(2); s.insert(4);
| cout << s.size();
- 3
+ 2
- 4
: У множині лише різні значення: 2 і 4.

? У якому порядку перебираються елементи `set<int>`?
- У порядку додавання
+ У порядку зростання
- У випадковому порядку
: `set` завжди тримає елементи впорядкованими.

? Що станеться після `map<string, int> m; cout << m["cat"];`?
+ Виведеться 0, і ключ `"cat"` з’явиться в словнику
- Програма аварійно зупиниться
- Помилка компіляції
: Звертання до відсутнього ключа через `[]` створює його зі значенням за замовчуванням.

? Як перевірити, чи є в множині `s` число `x`?
- `s[x]`
+ `s.count(x)`
- `s.find(x) == 0`
: `count` повертає 1, якщо елемент є, і 0, якщо немає.
```

#include <iostream>
#include <set>
using namespace std;

int main() {
    int n;
    cin >> n;
    set<long long> seen;
    bool found = false;
    long long answer = -1;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (!found && seen.count(x)) {
            found = true;
            answer = x;
        }
        seen.insert(x);
    }
    cout << answer << "\n";
    return 0;
}
```

#include <iostream>

using namespace std;

int main() {
    int n;
    long long k;
    cin >> n >> k;
    map<long long, long long> cnt;
    long long pairs = 0;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (cnt.count(k - x)) pairs += cnt[k - x];
        cnt[x]++;
    }
    cout << pairs << "\n";
    return 0;
}
```

## Коротко

- `set` — різні значення в порядку зростання; `insert`, `count`, `erase` працюють за ≈ log n кроків.
- `multiset` дозволяє повтори; одну копію видаляють через `erase(find(x))`.
- `map<K, V>` — словник «ключ → значення»; `m[key]++` — підрахунок частот будь-яких значень.
- `m[key]` створює відсутній ключ; для перевірки використовуй `m.count(key)`.
- «Дві суми» за один прохід: для кожного `x` перевір, чи траплялося `k − x`.
