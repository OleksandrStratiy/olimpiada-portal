# Масиви (vector)

Задача: дано `n` чисел, виведи їх у зворотному порядку. Звичайними змінними її не розв’язати: щоб вивести останнє число першим, треба спершу запам’ятати **всі** числа. А заводити тисячу змінних `a1`, `a2`, `a3`… неможливо. Тут потрібен **масив**.

> [!NOTE] У цьому уроці
> - що таке масив і як створити його за допомогою `vector`;
> - індекси: чому нумерація починається з нуля;
> - як прочитати і вивести масив;
> - як додавати елементи командою `push_back`;
> - звичайні масиви `int a[100]` і вихід за межі масиву.

## Масив — це ряд пронумерованих комірок

**Масив** — це багато змінних одного типу під одним іменем. Кожна комірка масиву називається **елементом** і має свій номер — **індекс**. Індекси в C++ починаються з **нуля**.

Масив із п’яти чисел можна уявити як ряд шафок:

| Індекс | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| Значення | 7 | 2 | 9 | 4 | 1 |

Тут `a[0]` дорівнює 7, `a[2]` — 9, а останній елемент — `a[4]`. Для масиву з `n` елементів індекси йдуть від **0 до n − 1**.

## Створення масиву

У сучасному C++ масиви найзручніше створювати за допомогою `vector` (бібліотека `vector`):

```cpp
vector<int> a(5);         // 5 елементів типу int, усі дорівнюють 0
vector<int> b(n);         // n елементів, де n — змінна
vector<int> c(n, -1);     // n елементів, кожен дорівнює -1
vector<long long> d(n);   // елементи типу long long
```

У кутових дужках — тип елементів, у круглих — їхня кількість.

З елементами працюють так само, як зі звичайними змінними: `a[0] = 7;`, `a[i] += 5;`, `cout << a[i];`.

## Читання і виведення

Тепер задача із зворотним порядком розв’язується легко:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];                 // читаємо всі числа
    }
    for (int i = n - 1; i >= 0; i--) {
        cout << a[i] << " ";         // виводимо з кінця
    }
    cout << "\n";
    return 0;
}
```

```input
5
7 2 9 4 1
```

```output
1 4 9 2 7
```

Цикл `for (int i = 0; i < n; i++)` — найчастіший цикл у програмах з масивами: `i` пробігає всі індекси від 0 до `n − 1`.

> [!IMPORTANT]
> Масив дозволяє переглядати дані **скільки завгодно разів** і в будь-якому порядку. Якщо в задачі потрібно, наприклад, спершу знайти середнє значення, а потім порахувати числа, більші за нього, — без масиву не обійтися.

## Розмір масиву і цикл по елементах

Кількість елементів повертає `a.size()`. Перебрати всі елементи можна ще коротше — циклом «для кожного»:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> a(4);
    for (int &x : a) cin >> x;       // & — щоб змінювати самі елементи
    int sum = 0;
    for (int x : a) sum += x;        // x по черзі дорівнює кожному елементу
    cout << a.size() << " " << sum << "\n";
    return 0;
}
```

```input
3 1 4 1
```

```output
4 9
```

`for (int x : a)` читається як «для кожного `x` з `a`». У такому циклі `x` — **копія** елемента. Щоб змінювати самі елементи (наприклад, читати в них), пишуть `int &x` — про знак `&` детальніше поговоримо в уроці про функції.

## Додавання елементів: `push_back`

Масив `vector` може рости. `push_back(x)` дописує елемент у кінець. Це зручно, коли наперед невідомо, скільки буде елементів. Наприклад, відберемо з усіх чисел лише парні:

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> even;                // порожній масив
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x % 2 == 0) even.push_back(x);
    }
    cout << even.size() << "\n";
    for (int x : even) cout << x << " ";
    cout << "\n";
    return 0;
}
```

```input
6
3 8 5 2 10 7
```

```output
3
8 2 10
```

Ще кілька корисних команд: `a.back()` — останній елемент, `a.pop_back()` — видалити останній елемент, `a.empty()` — чи порожній масив.

## Вихід за межі масиву

Для масиву з `n` елементів елемента `a[n]` **не існує**. Але C++ не перевіряє індекси: програма прочитає чи зіпсує чужу пам’ять. Результат непередбачуваний — від неправильної відповіді до аварійної зупинки (вердикт RE).

```cpp
vector<int> a(5);
a[5] = 10;    // помилка: останній індекс — 4
```

> [!CAUTION]
> Найчастіша причина — цикл `for (int i = 0; i <= n; i++)` замість `i < n`, або звернення до `a[i + 1]` для останнього `i`. Якщо програма «падає» без зрозумілої причини, перш за все перевір індекси.

## Звичайні масиви

У багатьох олімпіадних розв’язках ти побачиш масиви, успадковані від мови C:

```cpp
int a[100];        // рівно 100 елементів, розмір задано числом
```

Розмір такого масиву має бути відомий заздалегідь, тому його беруть «із запасом» відповідно до обмежень: якщо `n ≤ 10⁵`, пишуть `int a[100005];`. Такі масиви зазвичай оголошують **поза** `main` (глобально): тоді вони автоматично заповнені нулями, і великий розмір не спричиняє проблем.

```cpp
#include <iostream>
using namespace std;

int a[100005];   // глобальний масив: усі елементи дорівнюють 0

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    cout << a[0] + a[n - 1] << "\n";
    return 0;
}
```

```input
4
5 6 7 8
```

```output
13
```

> [!TIP]
> Поки вчишся, користуйся `vector` — він знає свій розмір і вміє рости. Але читати код зі звичайними масивами теж треба вміти.

## Скільки пам’яті займає масив

`int` займає 4 байти, `long long` — 8. Масив з мільйона `int` займає 4 мегабайти — це немало, але зазвичай допустимо (типове обмеження пам’яті на олімпіадах — 128 або 256 МБ). А от масив зі 100 мільйонів `long long` (800 МБ) у пам’ять уже не вміститься.

## Перевір себе

```quiz
? Який індекс має останній елемент масиву з 10 елементів?
- 10
+ 9
- 11
: Індекси починаються з нуля, тому останній — n − 1 = 9.

? Що виведе фрагмент?
| vector<int> a(3);
| a[0] = 5;
| a[2] = a[0] * 2;
| cout << a[0] + a[1] + a[2];
- 10
+ 15
- 25
: `a[1]` дорівнює 0 (новий `vector` заповнюється нулями), тож 5 + 0 + 10 = 15.

? Що робить `v.push_back(7)`?
+ Додає число 7 у кінець масиву
- Заміняє перший елемент на 7
- Видаляє елемент з індексом 7
: Масив стає на один елемент довшим, і останнім елементом стає 7.

? Що не так у циклі?
| vector<int> a(n);
| for (int i = 1; i <= n; i++) cin >> a[i];
- Нічого
+ Елемент `a[0]` не заповнюється, а `a[n]` не існує
- `cin` не можна використовувати з масивами
: Для `vector` з `n` елементів допустимі індекси від 0 до n − 1.
```

#include <iostream>

    for (int i = 0; i < n; i++) {
        cin >> a[i];
        sum += a[i];

        if (a[i] * n > sum) count++;
    }

=== solution
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    int count = 0;
    for (int i = 1; i + 1 < n; i++) {
        if (a[i] > a[i - 1] && a[i] > a[i + 1]) count++;
    }
    cout << count << "\n";
    return 0;
}

=== solution
#include <iostream>
#include <vector>
using namespace std;

int main() {

    vector<int> even, odd;
    for (int i = 0; i < n; i++) {

        else odd.push_back(x);

    for (int x : even) cout << x << " ";
    for (int x : odd) cout << x << " ";
    cout << "\n";
    return 0;
}

## Коротко

- Масив — багато змінних одного типу під одним іменем; `vector<int> a(n);` створює `n` нулів.
- Індекси від 0 до n − 1; `a[i]` — елемент з індексом `i`.
- `a.size()` — кількість елементів; `for (int x : a)` — перебір елементів; `for (int &x : a)` — щоб їх змінювати.
- `push_back(x)` дописує елемент у кінець.
- Вихід за межі масиву — тиха і небезпечна помилка; уважно перевіряй індекси.
- Звичайні масиви `int a[N];` мають сталий розмір; великі оголошують глобально.
