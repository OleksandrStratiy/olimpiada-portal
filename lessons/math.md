# Математичні функції

У C++ є готові функції для квадратного кореня, модуля, степеня, округлення, мінімуму й максимуму. У цьому уроці навчимося ними користуватися і дізнаємося, де вони можуть підвести.

> [!NOTE] У цьому уроці
> - що таке функція і як її викликати;
> - `sqrt`, `abs`, `pow`, `round`, `floor`, `ceil` з бібліотеки `cmath`;
> - `min`, `max` і `swap`;
> - як ділити з округленням угору без дробових чисел.

## Як викликати функцію

**Функція** — це готова «машинка»: ти даєш їй значення (аргументи) у круглих дужках, а вона повертає результат. Наприклад, `sqrt(25)` повертає 5 — квадратний корінь із 25. Результат функції можна вивести, записати у змінну або використати у виразі.

Математичні функції живуть у бібліотеці `cmath`, тому на початку програми потрібен рядок `#include <cmath>`.

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << sqrt(25) << "\n";
    double r = sqrt(2);
    cout << r << "\n";
    cout << sqrt(16) + sqrt(9) << "\n";
    return 0;
}
```

```output
5
1.41421
7
```

## Основні функції `cmath`

| Функція | Що робить | Приклад | Результат |
| --- | --- | --- | --- |
| `sqrt(x)` | квадратний корінь | `sqrt(49)` | 7 |
| `abs(x)` | модуль (число без знака) | `abs(-8)` | 8 |
| `pow(a, b)` | степінь: a в степені b | `pow(2, 10)` | 1024 |
| `round(x)` | округлення до найближчого цілого | `round(2.5)` | 3 |
| `floor(x)` | округлення вниз | `floor(2.7)` | 2 |
| `ceil(x)` | округлення вгору | `ceil(2.1)` | 3 |

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << abs(-8) << " " << abs(5) << "\n";
    cout << round(2.5) << " " << round(2.4) << "\n";
    cout << floor(2.7) << " " << ceil(2.1) << "\n";
    cout << floor(-2.5) << " " << ceil(-2.5) << "\n";
    return 0;
}
```

```output
8 5
3 2
2 3
-3 -2
```

Зверни увагу на від’ємні числа: `floor` завжди округлює **вниз** (до меншого числа), тому `floor(-2.5)` — це −3.

> [!WARNING] Обережно з `pow`
> `pow` працює з дробовими числами, тому для великих цілих може повернути не точно ціле значення (наприклад, 124.99999 замість 125), і після перетворення на `int` вийде 124. Квадрат числа надійніше рахувати множенням: `x * x`, куб — `x * x * x`.

> [!WARNING] Обережно з `ceil` і цілим діленням
> `ceil(7 / 2)` дорівнює 3, а не 4! Спершу виконується ціле ділення `7 / 2` = 3, і лише потім `ceil` округлює вже ціле число 3. Правильно — `ceil(7.0 / 2)`. А ще краще обійтися без дробових чисел, про це нижче.

## `min`, `max` і `swap`

Ці функції настільки корисні, що ти будеш користуватися ними постійно:

- `min(a, b)` — менше з двох значень;
- `max(a, b)` — більше з двох значень;
- `swap(a, b)` — міняє значення двох змінних місцями.

Щоб знайти найбільше з трьох чисел, можна вкласти один виклик в інший: `max(a, max(b, c))`. Або записати всі числа у фігурних дужках: `max({a, b, c})`.

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a = 7, b = 3, c = 12;
    cout << min(a, b) << " " << max(a, b) << "\n";
    cout << max(a, max(b, c)) << " " << min({a, b, c}) << "\n";
    swap(a, b);
    cout << a << " " << b << "\n";
    return 0;
}
```

```output
3 7
12 3
3 7
```

Ці функції описані в бібліотеці `algorithm`. Часто вони працюють і без неї, але надійніше підключити її явно.

> [!CAUTION]
> Обидва аргументи `min` і `max` мають бути одного типу. `max(x, 0)`, де `x` типу `long long`, не скомпілюється, бо `0` — це `int`. Пиши `max(x, 0LL)`.

## Ділення з округленням угору — без дробових чисел

Задача: у коробку вміщується `k` олівців. Скільки коробок потрібно для `n` олівців? Відповідь — `n / k` з округленням угору. З минулого уроку ти вже знаєш надійну формулу для натуральних чисел, яка обходиться без `double`:

```cpp
boxes = (n + k - 1) / k;
```

Чому вона працює? Якщо `n` ділиться на `k` націло, додане `k - 1` не «дотягує» до ще однієї цілої частки. А якщо є остача, хоча б 1, то додане `k - 1` разом з нею дає ще одну частку.

## Відстань між точками

Відстань між точками (x₁, y₁) і (x₂, y₂) на площині обчислюють за теоремою Піфагора: √((x₂ − x₁)² + (y₂ − y₁)²).

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    double x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;
    double dx = x2 - x1, dy = y2 - y1;
    cout << fixed << setprecision(3) << sqrt(dx * dx + dy * dy) << "\n";
    return 0;
}
```

```input
0 0 3 4
```

```output
5.000
```

## Перевір себе

```quiz
? Що виведе `cout << abs(-15);`?
- -15
+ 15
- 0
: Модуль — це число без знака.

? Чому дорівнює `floor(3.9)`?
+ 3
- 4
- 3.9
: `floor` округлює вниз — до найближчого меншого цілого.

? Що виведе `cout << ceil(9 / 4);`?
- 3
+ 2
- 2.25
: `9 / 4` — ціле ділення, воно дає 2, і `ceil(2)` — це 2. Правильно було б `ceil(9.0 / 4)`.

? Як найнадійніше обчислити квадрат цілого числа `x`?
- `pow(x, 2)`
+ `x * x`
- `sqrt(x)`
: `pow` працює з дробовими числами і може дати неточний результат. Множення цілих — точне.

? Скільки коробок по 6 яєць потрібно для 20 яєць, якщо рахувати за формулою `(n + k - 1) / k`?
- 3
+ 4
- 5
: (20 + 5) / 6 = 25 / 6 = 4. Справді: три коробки вміщують лише 18 яєць.
```

## Коротко

- Функцію викликають так: `назва(аргументи)`; вона повертає результат.
- `cmath`: `sqrt`, `abs`, `pow`, `round`, `floor`, `ceil`. Квадрат краще рахувати як `x * x`.
- `algorithm`: `min`, `max`, `swap`; `max(a, max(b, c))` або `max({a, b, c})`.
- Ділення з округленням угору без дробових чисел: `(n + k - 1) / k`.
- `ceil(7 / 2)` — пастка: ціле ділення виконується раніше за `ceil`.
