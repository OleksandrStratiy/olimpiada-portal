# Вкладені цикли

Цикл може стояти всередині іншого циклу. Так малюють таблиці й візерунки, перебирають усі пари чисел і розв’язують задачі «повним перебором» — коли комп’ютер просто перевіряє всі варіанти.

> [!NOTE] У цьому уроці
> - як працюють вкладені цикли;
> - прямокутники, трикутники і таблиці;
> - перебір пар і трійок чисел;
> - перша оцінка швидкості програми.

## Цикл у циклі

```cpp
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 4; j++) {
            cout << "(" << i << "," << j << ") ";
        }
        cout << "\n";
    }
    return 0;
}
```

```output
(1,1) (1,2) (1,3) (1,4) 
(2,1) (2,2) (2,3) (2,4) 
(3,1) (3,2) (3,3) (3,4) 
```

Зовнішній цикл (по `i`) виконується 3 рази. І **на кожній** його ітерації внутрішній цикл (по `j`) проходить повністю — 4 рази. Усього внутрішнє тіло виконується 3 · 4 = 12 разів.

Зручно думати так: зовнішній цикл перебирає **рядки**, внутрішній — **стовпці** в поточному рядку. Після внутрішнього циклу виводимо `"\n"`, щоб почати новий рядок.

> [!IMPORTANT]
> У вкладених циклів мають бути **різні** лічильники (`i` і `j`). Якщо у внутрішньому циклі теж написати `i`, він зіпсує лічильник зовнішнього.

## Прямокутник і трикутник

Прямокутник із зірочок: `n` рядків по `m` зірочок.

```cpp
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << "*";
        }
        cout << "\n";
    }
    return 0;
}
```

```input
3 5
```

```output
*****
*****
*****
```

А тепер трикутник: у рядку з номером `i` має бути `i` зірочок. Для цього межа внутрішнього циклу залежить від лічильника зовнішнього — `j <= i`:

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cout << "*";
        }
        cout << "\n";
    }
    return 0;
}
```

```input
4
```

```output
*
**
***
****
```

Згадай, як у третьому уроці ми малювали трикутник чотирма командами. Тепер програма малює трикутник будь-якого розміру.

## Таблиця множення

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            cout << i * j << "\t";
        }
        cout << "\n";
    }
    return 0;
}
```

```input
4
```

```output
1	2	3	4	
2	4	6	8	
3	6	9	12	
4	8	12	16	
```

Символ `\t` (табуляція) вирівнює стовпці.

## Перебір пар

Вкладені цикли перебирають **усі пари** чисел. Задача: скількома способами можна записати `n` як суму двох натуральних чисел `a + b`, де `a ≤ b`?

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (int a = 1; a <= n; a++) {
        for (int b = a; b <= n; b++) {   // b починається з a, щоб не рахувати пару двічі
            if (a + b == n) count++;
        }
    }
    cout << count << "\n";
    return 0;
}
```

```input
10
```

```output
5
```

Це 1 + 9, 2 + 8, 3 + 7, 4 + 6, 5 + 5. Зверни увагу на `b = a` у внутрішньому циклі: так кожна пара розглядається один раз (без «2 + 8» і «8 + 2» окремо).

> [!TIP]
> Цю задачу можна розв’язати й одним циклом: якщо відомо `a`, то `b = n − a` визначене однозначно. Часто один із вкладених циклів удається замінити обчисленням — і програма стає значно швидшою.

## Повний перебір

**Повний перебір** — це підхід «перевір усі варіанти». Він простий і надійний, якщо варіантів не надто багато. Наприклад: скільки існує прямокутних трикутників з цілими сторонами `a ≤ b < c ≤ n`? Перебираємо всі `a` і `b`, а `c` перевіряємо:

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    int count = 0;
    for (int a = 1; a <= n; a++) {
        for (int b = a; b <= n; b++) {
            int c2 = a * a + b * b;
            int c = (int)round(sqrt(c2));
            if (c <= n && c * c == c2) count++;
        }
    }
    cout << count << "\n";
    return 0;
}
```

```input
20
```

```output
6
```

Знайдені трійки: (3, 4, 5), (6, 8, 10), (5, 12, 13), (9, 12, 15), (8, 15, 17), (12, 16, 20).

## Скільки це працює?

Комп’ютер виконує приблизно **10⁸ простих дій за секунду** (сто мільйонів). Вкладені цикли швидко збільшують кількість дій:

| Цикли | n = 1000 | n = 100 000 |
| --- | --- | --- |
| один цикл до `n` | 10³ — миттєво | 10⁵ — миттєво |
| два вкладені до `n` | 10⁶ — миттєво | 10¹⁰ — близько хвилини |
| три вкладені до `n` | 10⁹ — кілька секунд | — безнадійно |

Тому перш ніж писати вкладені цикли, глянь на обмеження в умові задачі. Детально про це — в уроці «Складність алгоритмів».

> [!CAUTION]
> `break` у внутрішньому циклі завершує **лише внутрішній** цикл, а зовнішній продовжує роботу. Щоб вийти з обох, заводять прапорець і перевіряють його в зовнішньому циклі.

## Перевір себе

```quiz
? Скільки разів виведеться `*`?
| for (int i = 0; i < 4; i++)
|     for (int j = 0; j < 5; j++)
|         cout << "*";
- 9
+ 20
- 5
: На кожну з 4 ітерацій зовнішнього циклу внутрішній робить 5 ітерацій: 4 · 5 = 20.

? Скільки зірочок виведе фрагмент?
| for (int i = 1; i <= 4; i++)
|     for (int j = 1; j <= i; j++)
|         cout << "*";
- 4
+ 10
- 16
: 1 + 2 + 3 + 4 = 10 — це трикутник.

? Навіщо у внутрішньому циклі перебору пар пишуть `j = i + 1`?
+ Щоб кожна пара розглядалася один раз і без пар однакових елементів
- Щоб цикл працював швидше вдвічі, але давав ту саму відповідь для будь-якої задачі
- Щоб уникнути помилки компіляції
: Так ми розглядаємо лише пари `i < j`: без повторів на кшталт (2, 1) після (1, 2).

? Два вкладені цикли до `n = 100 000` — це скільки дій?
- 10⁵
- 2 · 10⁵
+ 10¹⁰
: 10⁵ · 10⁵ = 10¹⁰ — у сто разів більше, ніж комп’ютер встигає за секунду.
```

## Коротко

- Внутрішній цикл проходить повністю на кожній ітерації зовнішнього; кількість дій перемножується.
- Зовнішній цикл — рядки, внутрішній — стовпці; після внутрішнього циклу — `"\n"`.
- Межа внутрішнього циклу може залежати від зовнішнього лічильника (`j <= i` — трикутник).
- Перебір пар без повторів: `for (i …) for (j = i + 1 …)`.
- Комп’ютер робить ≈10⁸ дій за секунду — оцінюй кількість ітерацій вкладених циклів заздалегідь.
- `break` виходить лише з внутрішнього циклу.
