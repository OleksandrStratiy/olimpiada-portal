# Складні умови

Іноді одного порівняння мало. «Число двоцифрове» — це «не менше 10 **і** не більше 99». «Вихідний день» — це «субота **або** неділя». Щоб записувати такі умови, у C++ є логічні операції.

> [!NOTE] У цьому уроці
> - логічні операції `&&` (і), `||` (або), `!` (не);
> - як перевірити, що число лежить у проміжку;
> - змінні типу `bool`;
> - класичні задачі: високосний рік, існування трикутника, ходи шахових фігур.

## Три логічні операції

| Операція | Запис | Коли істинна |
| --- | --- | --- |
| і | `A && B` | коли істинні **обидві** умови |
| або | `A \|\| B` | коли істинна **хоча б одна** з умов |
| не | `!A` | коли `A` хибна |

Символ `|` — вертикальна риска, на клавіатурі вона над <kbd>Enter</kbd> разом із зворотною косою рискою (з <kbd>Shift</kbd>). Для «або» її пишуть двічі: `||`.

Ось усі можливі випадки (таблиця істинності):

| A | B | A && B | A \|\| B |
| --- | --- | --- | --- |
| хиба | хиба | хиба | хиба |
| хиба | істина | хиба | істина |
| істина | хиба | хиба | істина |
| істина | істина | істина | істина |

## Число в проміжку

Щоб перевірити, що число `x` лежить від 10 до 99 включно, потрібні **дві** перевірки, з’єднані через «і»:

```cpp
#include <iostream>
using namespace std;

int main() {
    int x;
    cin >> x;
    if (x >= 10 && x <= 99) {
        cout << "two-digit" << "\n";
    } else {
        cout << "not two-digit" << "\n";
    }
    return 0;
}
```

```input
42
```

```output
two-digit
```

> [!CAUTION]
> Запис `10 <= x <= 99`, як у математиці, у C++ **не працює**. Спершу обчислюється `10 <= x`, і виходить `true` або `false`, тобто 1 або 0. А далі 1 чи 0 порівнюється з 99 — це завжди істина. Ось доказ:
> ```cpp
> int x = 500;
> if (10 <= x <= 99) cout << "two-digit";   // виведе two-digit!
> ```
> Правильно: `10 <= x && x <= 99`.

## «Або»: хоча б одна умова

Дні тижня пронумеровано від 1 до 7. Вихідні — субота (6) і неділя (7):

```cpp
#include <iostream>
using namespace std;

int main() {
    int d;
    cin >> d;
    if (d == 6 || d == 7) {
        cout << "weekend" << "\n";
    } else {
        cout << "workday" << "\n";
    }
    return 0;
}
```

```input
7
```

```output
weekend
```

Зверни увагу: `d == 6 || 7` — неправильно. Кожна частина «або» має бути повною умовою: `d == 6 || d == 7`.

## «Не»

Операція `!` перетворює істину на хибу і навпаки. Наприклад, `!(x > 0)` — те саме, що `x <= 0`. Часто `!` застосовують до змінних типу `bool`.

## Змінні типу `bool`

Результат умови можна зберегти в змінній типу `bool` і використати пізніше. Це робить код зрозумілішим.

Класичний приклад — **високосний рік**. За григоріанським календарем рік високосний, якщо він ділиться на 4, але не ділиться на 100, **або** якщо він ділиться на 400. Тому 2024 — високосний, 1900 — ні, а 2000 — так.

```cpp
#include <iostream>
using namespace std;

int main() {
    int y;
    cin >> y;
    bool leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
    if (leap) {
        cout << "YES" << "\n";
    } else {
        cout << "NO" << "\n";
    }
    return 0;
}
```

```input
1900
```

```output
NO
```

## Порядок виконання

Спершу виконується `!`, потім порівняння (`<`, `==` і т. д.), потім `&&` і лише потім `||` — як множення виконується раніше за додавання. Але щоб не згадувати правила й не помилятися, **став дужки** — як у прикладі з високосним роком.

## Скорочене обчислення

Якщо ліва частина `&&` хибна, права вже не обчислюється: відповідь і так «хиба». Так само для `||`: якщо ліва частина істинна, права не перевіряється. Це корисно, щоб уникнути ділення на нуль:

```cpp
if (b != 0 && a % b == 0) {
    cout << "a divides by b";
}
```

Якщо `b` дорівнює нулю, перевірка `a % b` просто не виконається.

## Задачі з геометрії і шахів

**Чи існує трикутник** зі сторонами `a`, `b`, `c`? Так, якщо кожна сторона менша за суму двох інших:

```cpp
if (a + b > c && a + c > b && b + c > a)
```

**Шахова дошка.** Клітинки нумеруються від 1 до 8 по горизонталі і по вертикалі. Клітинка (1, 1) — чорна, і кольори чергуються. Тому клітинка `(x, y)` чорна, якщо сума `x + y` парна.

**Тура** ходить по горизонталі або вертикалі: з `(x1, y1)` вона дістанеться `(x2, y2)` за один хід, якщо `x1 == x2 || y1 == y2` (і клітинки різні).

**Слон** ходить по діагоналі: різниця по горизонталі дорівнює різниці по вертикалі, тобто `abs(x1 - x2) == abs(y1 - y2)`.

## Перевір себе

```quiz
? Коли істинна умова `A && B`?
- Коли істинна хоча б одна з умов
+ Коли істинні обидві умови
- Коли обидві хибні
: `&&` — це «і»: потрібно, щоб виконувалися обидві умови.

? Як правильно перевірити, що `x` від 1 до 10 включно?
- `1 <= x <= 10`
+ `x >= 1 && x <= 10`
- `x >= 1 || x <= 10`
: Потрібні дві перевірки, з’єднані через «і». Варіант з `||` істинний для будь-якого числа.

? Що виведе фрагмент?
| int a = 5, b = 0;
| if (a > 3 || b > 3) cout << "yes";
| else cout << "no";
+ `yes`
- `no`
: Для «або» достатньо, щоб істинною була одна умова: 5 > 3.

? Чи високосний 2100 рік?
- Так, бо ділиться на 4
+ Ні, бо ділиться на 100, але не на 400
- Так, бо ділиться на 100
: 2100 ділиться на 100, але не на 400, тому він не високосний.

? Яка умова означає «`n` не ділиться ні на 2, ні на 3»?
- `n % 2 != 0 || n % 3 != 0`
+ `n % 2 != 0 && n % 3 != 0`
- `!(n % 2 == 0 && n % 3 == 0)`
: Обидві умови мають виконуватися одночасно, тому «і». Варіант з `||` пропустить, наприклад, 4 (не ділиться на 3).
```

## Коротко

- `&&` — «і» (обидві умови), `||` — «або» (хоча б одна), `!` — «не».
- Проміжок перевіряють двома умовами: `a <= x && x <= b`; запис `a <= x <= b` не працює.
- Кожна частина складної умови — повне порівняння: `d == 6 || d == 7`, а не `d == 6 || 7`.
- Результат умови можна зберегти в змінній `bool`.
- Став дужки, щоб не помилитися в порядку виконання.
