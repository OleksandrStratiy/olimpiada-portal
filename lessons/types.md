# Типи даних

Досі всі наші змінні мали тип `int`. Але в `int` не вміщаються дуже великі числа, а дробових чисел він не зберігає зовсім. У цьому уроці познайомимося з іншими типами і з однією з найпідступніших помилок на олімпіадах — **переповненням**.

> [!NOTE] У цьому уроці
> - які числа вміщує `int` і що таке переповнення;
> - коли потрібен `long long`;
> - дробові числа `double` і як вивести потрібну кількість знаків після коми;
> - символи `char` і логічний тип `bool`.

## Скільки вміщує `int`

Змінна типу `int` займає в пам’яті 4 байти, тобто 32 біти. Тому кількість можливих значень обмежена: від −2 147 483 648 до 2 147 483 647. Приблизно **від −2·10⁹ до 2·10⁹** — це варто запам’ятати.

Що буде, якщо вийти за межу? Число «перескочить» на інший кінець діапазону, як лічильник кілометрів у старому автомобілі. Це називають **переповненням**:

```cpp
#include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;
    cout << a + a << "\n";
    return 0;
}
```

```input
2000000000
```

```output
-294967296
```

Два мільярди плюс два мільярди дорівнюють чотирьом мільярдам, а програма вивела від’ємне число! Компілятор не повідомить про таку помилку, і програма не зупиниться — вона просто тихо видасть неправильну відповідь.

## `long long` — для великих чисел

Тип `long long` займає 8 байтів і вміщує числа приблизно **від −9·10¹⁸ до 9·10¹⁸**. Цього вистачає майже для всіх олімпіадних задач.

```cpp
#include <iostream>
using namespace std;

int main() {
    long long a;
    cin >> a;
    cout << a + a << "\n";
    return 0;
}
```

```input
2000000000
```

```output
4000000000
```

> [!IMPORTANT]
> Перш ніж писати код, подивись на обмеження в умові і оціни, наскільки великою може бути **відповідь і всі проміжні результати**. Якщо більше за 2·10⁹ — бери `long long`. Наприклад, якщо `a` і `b` до 10⁹, то їхня сума вміщується в `int` лише ледь-ледь, а добуток (до 10¹⁸) — тільки в `long long`.

### Підступне множення

Подивись на цю програму:

```cpp
#include <iostream>
using namespace std;

int main() {
    int x, y;
    cin >> x >> y;
    long long bad = x * y;
    long long good = 1LL * x * y;
    cout << bad << " " << good << "\n";
    return 0;
}
```

```input
100000 100000
```

```output
1410065408 10000000000
```

Змінна `bad` має тип `long long`, але відповідь неправильна. Чому? Комп’ютер спершу обчислює праву частину `x * y`. Обидва множники — `int`, тому й множення виконується в `int` і переповнюється. Лише потім уже зіпсований результат записується в `long long`.

Щоб множення відбувалося в `long long`, хоча б один множник має бути цього типу. Звідси трюк `1LL * x * y`: `1LL` — це одиниця типу `long long` (суфікс `LL`). А найпростіше — одразу оголошувати змінні як `long long`.

## Дробові числа: `double`

Для дробових чисел є тип `double`. У коді дробову частину відділяють **крапкою**, а не комою: `3.14`, `0.5`, `-2.75`.

```cpp
#include <iostream>
using namespace std;

int main() {
    double price = 12.5;
    double total = price * 3;
    cout << total << "\n";
    cout << 7 / 2 << " " << 7.0 / 2 << " " << 7 / 2.0 << "\n";
    return 0;
}
```

```output
37.5
3 3.5 3.5
```

Правило: якщо **обидва** числа цілі, ділення ціле (`7 / 2` = 3). Якщо хоча б одне дробове — результат дробовий (`7.0 / 2` = 3.5).

Щоб поділити дві цілі змінні «по-справжньому», одну з них перетворюють на `double`:

```cpp
int a = 7, b = 2;
double r = (double)a / b;   // 3.5
```

### Скільки знаків після коми

За замовчуванням `cout` виводить до 6 значущих цифр, а дуже великі числа — в незвичному вигляді на кшталт `1.23457e+08`. Олімпіадні задачі часто вимагають точну кількість знаків після коми, наприклад «з точністю до двох знаків». Для цього підключають бібліотеку `iomanip` і пишуть `fixed << setprecision(k)`:

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x = 10.0 / 3;
    cout << x << "\n";
    cout << fixed << setprecision(2) << x << "\n";
    cout << setprecision(4) << x << "\n";
    cout << 2.5 << "\n";
    return 0;
}
```

```output
3.33333
3.33
3.3333
2.5000
```

Після `fixed << setprecision(k)` усі наступні дробові числа виводяться рівно з `k` знаками після коми (з округленням).

> [!WARNING]
> Дробові числа зберігаються в пам’яті неточно. Наприклад, `0.1 + 0.2` насправді трохи відрізняється від `0.3`. Тому дробові числа ніколи не порівнюють через `==`, а там, де можна обійтися цілими числами, краще обходитися ними.

## Перетворення типів

- Ціле число автоматично перетворюється на дробове, коли це потрібно: `double d = 5;` — у `d` буде 5.0.
- Дробове число при перетворенні на ціле **втрачає дробову частину** (без округлення!): `(int)3.99` дорівнює 3, а `(int)-3.99` дорівнює −3.

```cpp
#include <iostream>
using namespace std;

int main() {
    double x = 3.99;
    int n = (int)x;
    cout << n << "\n";
    return 0;
}
```

```output
3
```

## Символи і логічні значення

**`char`** зберігає один символ: літеру, цифру, розділовий знак. Символ записують в **одинарних** лапках: `'A'`, `'7'`, `'?'`. Детально про символи поговоримо в окремому уроці.

**`bool`** (логічний тип) має лише два значення: `true` (істина) і `false` (хиба). Він знадобиться в умовах. При виведенні `true` перетворюється на 1, а `false` — на 0.

```cpp
#include <iostream>
using namespace std;

int main() {
    char letter = 'A';
    bool isBig = 5 > 3;
    cout << letter << " " << isBig << "\n";
    return 0;
}
```

```output
A 1
```

## Підсумкова таблиця

| Тип | Що зберігає | Діапазон | Коли брати |
| --- | --- | --- | --- |
| `int` | цілі числа | ≈ ±2·10⁹ | лічильники, номери, невеликі числа |
| `long long` | цілі числа | ≈ ±9·10¹⁸ | суми, добутки, усе, що може перевищити 2·10⁹ |
| `double` | дробові числа | ≈ 15 значущих цифр | середні значення, геометрія, відсотки |
| `char` | один символ | — | літери, цифри як символи |
| `bool` | `true` або `false` | — | позначки «так/ні» |

## Коротко

- `int` — до ≈ 2·10⁹; більші числа переповнюються без жодного попередження.
- `long long` — до ≈ 9·10¹⁸; бери його для великих сум і добутків. Пам’ятай про трюк `1LL * a * b`.
- `double` — дробові числа; `7 / 2` = 3, а `7.0 / 2` = 3.5.
- `fixed << setprecision(k)` з бібліотеки `iomanip` виводить рівно `k` знаків після коми.
- `(int)x` відкидає дробову частину; `char` — символ в одинарних лапках; `bool` — `true` або `false`.
