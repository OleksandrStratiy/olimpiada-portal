# Рекурсія

Функція може викликати не лише інші функції, а й **саму себе**. Це називається **рекурсією**. Звучить як фокус, але рекурсія — природний спосіб розв’язувати задачі, які складаються з менших копій самих себе. На ній побудовано перебір варіантів, динамічне програмування, обхід графів.

> [!NOTE] У цьому уроці
> - що таке рекурсія, база і крок рекурсії;
> - як виконується рекурсивна функція;
> - факторіал, сума цифр, степінь, НСД;
> - чому наївні числа Фібоначчі рахуються повільно;
> - задача про Ханойські вежі.

## Факторіал через себе

Згадай факторіал: 5! = 1 · 2 · 3 · 4 · 5. Помітимо, що 5! = 5 · 4!, а 4! = 4 · 3! — тобто факторіал виражається через факторіал меншого числа: **n! = n · (n − 1)!**. І ще потрібна точка зупинки: **0! = 1**.

Так і запишемо:

```cpp
#include <iostream>
using namespace std;

long long fact(int n) {
    if (n == 0) return 1;          // база рекурсії
    return n * fact(n - 1);        // крок рекурсії
}

int main() {
    cout << fact(5) << "\n";
    cout << fact(20) << "\n";
    return 0;
}
```

```output
120
2432902008176640000
```

Кожна рекурсивна функція має дві частини:

- **база рекурсії** — простий випадок, для якого відповідь відома одразу (тут `n == 0`);
- **крок рекурсії** — зведення задачі до меншої такої самої задачі (тут `fact(n - 1)`).

## Як це виконується

Простежимо `fact(3)`:

```text
fact(3) = 3 * fact(2)
              fact(2) = 2 * fact(1)
                            fact(1) = 1 * fact(0)
                                          fact(0) = 1
                            fact(1) = 1 * 1 = 1
              fact(2) = 2 * 1 = 2
fact(3) = 3 * 2 = 6
```

Виклики «занурюються» все глибше, поки не дійдуть до бази. Потім результати повертаються назад, і кожен виклик завершує своє множення. Комп’ютер пам’ятає всі незавершені виклики в спеціальній області пам’яті — **стеку викликів**.

> [!CAUTION] Без бази — нескінченна рекурсія
> Якщо забути базу або крок не наближає до неї, функція викликатиме себе знову і знову, поки не закінчиться пам’ять стеку. Програма аварійно зупиниться (вердикт RE). Перевір: чи завжди аргумент рано чи пізно потрапляє в базу?

## Ще приклади

**Сума цифр**: сума цифр числа — це остання цифра плюс сума цифр решти числа. База: у нуля сума цифр 0.

```cpp
int digitSum(int n) {
    if (n == 0) return 0;
    return n % 10 + digitSum(n / 10);
}
```

**НСД** за алгоритмом Евкліда записується рекурсією майже дослівно:

```cpp
long long gcd(long long a, long long b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

**Виведення цифр по порядку.** Розбираючи число циклом, ми отримуємо цифри з кінця. Рекурсія дозволяє вивести їх з початку: спершу «виведи все, крім останньої цифри», а потім — останню цифру.

```cpp
#include <iostream>
using namespace std;

void printDigits(int n) {
    if (n >= 10) printDigits(n / 10);   // спершу — старші цифри
    cout << n % 10 << " ";              // потім — остання
}

int main() {
    printDigits(4827);
    cout << "\n";
    return 0;
}
```

```output
4 8 2 7 
```

## Швидке піднесення до степеня

Рекурсія допомагає не лише записати, а й **прискорити** обчислення. Обчислювати aⁿ множенням n разів довго, якщо n — мільярд. Але aⁿ = (a^(n/2))² для парного n і aⁿ = a · aⁿ⁻¹ для непарного. Тоді показник щоразу зменшується щонайменше вдвічі:

```cpp
#include <iostream>
using namespace std;

long long power(long long a, int n) {
    if (n == 0) return 1;
    if (n % 2 == 0) {
        long long half = power(a, n / 2);
        return half * half;
    }
    return a * power(a, n - 1);
}

int main() {
    cout << power(2, 10) << " " << power(3, 39) << "\n";
    return 0;
}
```

```output
1024 4052555153018976267
```

Для n = 10⁹ знадобиться лише близько 60 викликів. В уроці «Теорія чисел» цей прийом поєднаємо з остачами, щоб працювати з величезними степенями.

## Пастка: числа Фібоначчі

**Числа Фібоначчі**: F₁ = F₂ = 1, а кожне наступне — сума двох попередніх: 1, 1, 2, 3, 5, 8, 13, 21, … Рекурсія напрошується сама:

```cpp
long long fib(int n) {
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);
}
```

Це правильно, але **дуже повільно**. Подивись: `fib(5)` викликає `fib(4)` і `fib(3)`; `fib(4)` знову викликає `fib(3)` і `fib(2)` — одне й те саме обчислюється багато разів. Кількість викликів росте майже як самі числа Фібоначчі: для n = 50 — понад десять мільярдів викликів.

Виправити це просто: запам’ятовувати вже обчислені значення в масиві і не рахувати їх удруге. Цю ідею — **запам’ятовування** — ми розвинемо в уроці «Динамічне програмування».

## Ханойські вежі

Класична задача, яку важко розв’язати без рекурсії. Є три стрижні. На першому — `n` дисків різного розміру: найбільший унизу, найменший нагорі. Треба перенести всі диски на третій стрижень. За один хід можна переносити лише один верхній диск, і не можна класти більший диск на менший.

Рекурсивна ідея: щоб перенести `n` дисків з `from` на `to`:

1. перенести `n − 1` верхніх дисків з `from` на допоміжний стрижень `via`;
2. перенести найбільший диск з `from` на `to`;
3. перенести `n − 1` дисків з `via` на `to`.

```cpp
#include <iostream>
using namespace std;

void hanoi(int n, int from, int to, int via) {
    if (n == 0) return;
    hanoi(n - 1, from, via, to);
    cout << from << " -> " << to << "\n";
    hanoi(n - 1, via, to, from);
}

int main() {
    hanoi(3, 1, 3, 2);
    return 0;
}
```

```output
1 -> 3
1 -> 2
3 -> 2
1 -> 3
2 -> 1
2 -> 3
1 -> 3
```

Для `n` дисків знадобиться 2ⁿ − 1 ходів. Ми не продумували кожен хід — лише описали, як звести задачу з `n` дисками до задачі з `n − 1`. Решту зробила рекурсія.

> [!TIP]
> Пишучи рекурсію, не намагайся простежити в голові всі виклики. Достатньо переконатися у двох речах: база правильна, і якщо функція правильно працює для менших значень, то крок дає правильну відповідь для більшого.

## Перевір себе

```quiz
? Що таке база рекурсії?
- Перший рядок функції
+ Випадок, для якого відповідь відома без рекурсивного виклику
- Найбільше можливе значення аргументу
: База зупиняє рекурсію: без неї функція викликала б себе нескінченно.

? Що поверне `f(4)`?
| int f(int n) {
|     if (n == 0) return 0;
|     return n + f(n - 1);
| }
- 4
+ 10
- 24
: 4 + 3 + 2 + 1 + 0 = 10.

? Що виведе `p(3)`?
| void p(int n) {
|     if (n == 0) return;
|     p(n - 1);
|     cout << n;
| }
+ `123`
- `321`
- `3`
: Спершу відбуваються всі виклики аж до `p(0)`, а виведення відбувається на зворотному шляху: 1, 2, 3.

? Чому наївна рекурсія для чисел Фібоначчі повільна?
- Бо рекурсія завжди повільна
+ Бо ті самі значення обчислюються багато разів
- Бо числа Фібоначчі не вміщуються в `long long`
: Виклики дублюються, і їхня кількість росте експоненційно. Рятує запам’ятовування результатів.
```

=== solution
#include <iostream>
using namespace std;

void hanoi(int n, int from, int to, int via) {

id: power-rec

=== input

=== output
Значення aⁿ.
=== example

=== example
-3 3
---

=== test
1 1000000000
---
1
=== test
-1 999999999
---
-1
=== test

---

=== test
10 18
---

=== test
1000000000 2
---

=== hint
Для парного `n` обчисли `half = power(a, n / 2)` один раз і поверни `half * half`. Для непарного — `a * power(a, n - 1)`.
=== solution
#include <iostream>
using namespace std;

long long power(long long a, long long n) {
    if (n == 0) return 1;
    if (n % 2 == 0) {
        long long half = power(a, n / 2);
        return half * half;
    }
    return a * power(a, n - 1);
}

int main() {
    long long a, n;
    cin >> a >> n;
    cout << power(a, n) << "\n";
    return 0;
}

## Коротко

- Рекурсивна функція викликає саму себе; потрібні база (простий випадок) і крок (зведення до меншої задачі).
- Незавершені виклики зберігаються в стеку; без бази рекурсія нескінченна і програма падає.
- Факторіал, сума цифр, НСД, швидкий степінь, Ханойські вежі природно записуються рекурсією.
- Якщо рекурсія багато разів рахує одне й те саме (як наївний Фібоначчі), результати треба запам’ятовувати.
