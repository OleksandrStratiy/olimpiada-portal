# Символи (char)

Комп’ютер уміє працювати лише з числами. Як же він зберігає літери? Дуже просто: кожному символу відповідає **число-код**. У цьому уроці розберемося з типом `char` і навчимося перетворювати літери і цифри.

> [!NOTE] У цьому уроці
> - тип `char` і коди символів (таблиця ASCII);
> - як перетворити символ-цифру на число і навпаки;
> - як перевірити, чи символ — літера чи цифра;
> - великі й малі літери;
> - шифр Цезаря.

## Тип `char`

Змінна типу `char` зберігає **один** символ. Символи записують в **одинарних** лапках:

```cpp
char c = 'A';
char digit = '7';
char space = ' ';
```

Не плутай: `'A'` в одинарних лапках — це один символ, а `"A"` в подвійних — рядок (текст), хай навіть з одного символу. А `'7'` — це символ-цифра, а не число 7!

## Коди символів

Усередині комп’ютера `char` — це невелике ціле число, **код символу**. Відповідність між символами і кодами задає таблиця **ASCII**. Запам’ятовувати її не треба, але корисно знати, як вона влаштована:

| Символи | Коди |
| --- | --- |
| пробіл | 32 |
| `'0'` … `'9'` | 48 … 57 |
| `'A'` … `'Z'` | 65 … 90 |
| `'a'` … `'z'` | 97 … 122 |

Головне: **цифри, великі латинські літери і малі латинські літери йдуть підряд**, у звичному порядку. Тому з символами можна робити арифметику:

```cpp
#include <iostream>
using namespace std;

int main() {
    char c = 'A';
    cout << (int)c << "\n";          // код символу
    cout << (char)(c + 1) << "\n";   // наступний символ
    cout << (char)99 << "\n";        // символ з кодом 99
    cout << 'z' - 'a' << "\n";       // відстань між літерами
    return 0;
}
```

```output
65
B
c
25
```

`(int)c` перетворює символ на його код, а `(char)x` — код на символ. Різниця двох символів — звичайне число.

## Цифри: символ ↔ число

Символ `'7'` має код 55, а зовсім не 7. Щоб отримати з символу-цифри саме число, від нього віднімають `'0'`:

```cpp
#include <iostream>
using namespace std;

int main() {
    char c = '7';
    int d = c - '0';                  // 55 - 48 = 7
    cout << d * 2 << "\n";
    char back = (char)('0' + 3);      // число 3 → символ '3'
    cout << back << "\n";
    return 0;
}
```

```output
14
3
```

> [!IMPORTANT]
> `c - '0'` — один із найчастіших прийомів в олімпіадних задачах. Він знадобиться щоразу, коли число дано як послідовність символів-цифр.

## Перевірка символу

Оскільки літери й цифри йдуть підряд, перевірки виглядають так:

```cpp
if (c >= '0' && c <= '9')   // цифра
if (c >= 'a' && c <= 'z')   // мала латинська літера
if (c >= 'A' && c <= 'Z')   // велика латинська літера
```

У бібліотеці `cctype` є готові функції:

| Функція | Що перевіряє чи робить |
| --- | --- |
| `isdigit(c)` | чи є `c` цифрою |
| `isalpha(c)` | чи є `c` латинською літерою |
| `isupper(c)`, `islower(c)` | чи є `c` великою / малою літерою |
| `isspace(c)` | чи є `c` пробілом, табуляцією чи переходом на новий рядок |
| `toupper(c)`, `tolower(c)` | повертає велику / малу літеру |

## Великі й малі літери

Відстань між малою літерою і відповідною великою однакова для всіх літер: `'a' - 'A'` дорівнює 32. Тому перетворення регістру — проста арифметика:

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    cin >> c;
    if (c >= 'a' && c <= 'z') {
        c = c - 'a' + 'A';            // номер літери в алфавіті + 'A'
    }
    cout << c << "\n";
    return 0;
}
```

```input
g
```

```output
G
```

Вираз `c - 'a'` — це **номер літери в алфавіті** від 0 (для `a`) до 25 (для `z`). Цей номер дуже корисний: наприклад, масив `cnt[26]` дозволяє порахувати, скільки разів трапилася кожна літера.

## Читання символів

`cin >> c` для змінної типу `char` читає один символ, **пропускаючи пробіли** і переходи на новий рядок. Так зручно читати поле з символів, як у задачі «Сапер». Щоб прочитати символи до певного «кінцевого» символу, підійде цикл:

```cpp
#include <iostream>
using namespace std;

int main() {
    char c;
    int digits = 0;
    while (cin >> c && c != '.') {
        if (c >= '0' && c <= '9') digits++;
    }
    cout << digits << "\n";
    return 0;
}
```

```input
a1b22c333.
```

```output
6
```

> [!WARNING] Українські літери
> Літери українського алфавіту не вміщуються в один `char`: кожна займає два байти. Тому в олімпіадних задачах текст майже завжди складається з латинських літер, цифр і розділових знаків.

## Шифр Цезаря

Давньоримський полководець Юлій Цезар шифрував листи, зсуваючи кожну літеру на 3 позиції алфавітом: `a` → `d`, `b` → `e`, …, а кінець алфавіту «загортається» на початок: `x` → `a`, `y` → `b`, `z` → `c`.

З номером літери це записується однією формулою: новий номер — `(c - 'a' + k) % 26`, а нова літера — `'a'` плюс цей номер.

```cpp
#include <iostream>
using namespace std;

int main() {
    int k = 3;
    char c = 'y';
    char e = (char)('a' + (c - 'a' + k) % 26);
    cout << e << "\n";
    return 0;
}
```

```output
b
```

## Перевір себе

```quiz
? Що виведе `cout << '5' - '0';`?
+ 5
- 53
- '5'
: Різниця кодів символів `'5'` (53) і `'0'` (48) дорівнює 5.

? Що виведе фрагмент?
| char c = 'C';
| cout << (char)(c + 2);
- C2
+ E
- 69
: Літери йдуть підряд: C, D, E.

? Яка умова перевіряє, що `c` — мала латинська літера?
- `c >= 'a' || c <= 'z'`
+ `c >= 'a' && c <= 'z'`
- `c == 'a'`
: Символ має бути одночасно не меншим за `'a'` і не більшим за `'z'`.

? Чому дорівнює `'d' - 'a'`?
- 4
+ 3
- 100
: Це номер літери `d` в алфавіті, якщо рахувати з нуля: a — 0, b — 1, c — 2, d — 3.

? Чим відрізняються `'A'` і `"A"`?
+ `'A'` — один символ, `"A"` — рядок
- Нічим
- `"A"` — код символу A
: Одинарні лапки — символ (`char`), подвійні — рядок тексту.
```

## Коротко

- `char` зберігає один символ; символи пишуть в одинарних лапках: `'A'`.
- Кожен символ має код; цифри, великі й малі латинські літери йдуть підряд.
- `c - '0'` — значення цифри; `'0' + d` — символ цифри; `c - 'a'` — номер літери в алфавіті.
- Перевірки: `c >= 'a' && c <= 'z'` тощо, або функції `isdigit`, `isalpha`, `toupper` з `cctype`.
- `cin >> c` пропускає пробіли і читає наступний символ.
