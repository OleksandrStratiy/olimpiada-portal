# Двовимірні масиви

Шахова дошка, карта лабіринту, таблиця оцінок класу, поле гри «Сапер» — це **таблиці**: дані в них розташовані рядками і стовпцями. Для таблиць у програмуванні використовують **двовимірні масиви** (матриці).

> [!NOTE] У цьому уроці
> - як створити таблицю `n × m` і звертатися до клітинок;
> - читання і виведення таблиці;
> - суми рядків і стовпців, діагоналі;
> - сусідні клітинки і перевірка меж поля.

## Масив масивів

Двовимірний масив — це масив, кожен елемент якого — теж масив (рядок таблиці). Таблиця з `n` рядків і `m` стовпців, заповнена нулями:

```cpp
vector<vector<int>> a(n, vector<int>(m, 0));
```

Звучить громіздко, але читається просто: «`n` рядків, кожен з яких — `vector<int>` довжини `m`».

До клітинки звертаються двома індексами: `a[i][j]` — рядок `i`, стовпець `j`. Обидва індекси, як завжди, починаються з нуля.

| | стовпець 0 | стовпець 1 | стовпець 2 |
| --- | --- | --- | --- |
| **рядок 0** | `a[0][0]` | `a[0][1]` | `a[0][2]` |
| **рядок 1** | `a[1][0]` | `a[1][1]` | `a[1][2]` |

## Читання і виведення

Таблицю читають і виводять двома вкладеними циклами: зовнішній — по рядках, внутрішній — по стовпцях.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    // виведемо таблицю, збільшивши кожне число вдвічі
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << a[i][j] * 2 << " ";
        }
        cout << "\n";
    }
    return 0;
}
```

```input
2 3
1 2 3
4 5 6
```

```output
2 4 6 
8 10 12 
```

## Суми рядків і стовпців

Сума рядка `i` — це сума `a[i][j]` по всіх `j`. Сума стовпця `j` — сума `a[i][j]` по всіх `i`. Різниця лише в тому, який індекс «бігає» у внутрішньому циклі.

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<int>> a(n, vector<int>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    for (int i = 0; i < n; i++) {          // суми рядків
        int s = 0;
        for (int j = 0; j < m; j++) s += a[i][j];
        cout << s << " ";
    }
    cout << "\n";
    for (int j = 0; j < m; j++) {          // суми стовпців
        int s = 0;
        for (int i = 0; i < n; i++) s += a[i][j];
        cout << s << " ";
    }
    cout << "\n";
    return 0;
}
```

```input
2 3
1 2 3
4 5 6
```

```output
6 15 
5 7 9 
```

## Квадратні таблиці і діагоналі

У квадратній таблиці `n × n` є дві діагоналі:

- **головна** — з лівого верхнього кута в правий нижній: клітинки `a[i][i]`;
- **побічна** — з правого верхнього кута в лівий нижній: клітинки `a[i][n - 1 - i]`.

Клітинки **над** головною діагоналлю мають `j > i`, а **під** нею — `j < i`.

**Транспонування** — це «віддзеркалення» таблиці відносно головної діагоналі: рядки стають стовпцями. Елемент `a[i][j]` переходить у `b[j][i]`, а таблиця `n × m` перетворюється на таблицю `m × n`.

## Сусідні клітинки

У задачах на клітчастих полях (лабіринти, ігри, карти) постійно треба переглядати **сусідів** клітинки `(i, j)`. Чотири сусіди по сторонах — це `(i − 1, j)`, `(i + 1, j)`, `(i, j − 1)` і `(i, j + 1)`. Зручно записати зміщення в масиви і перебирати їх циклом:

```cpp
int di[4] = {-1, 1, 0, 0};
int dj[4] = {0, 0, -1, 1};
for (int k = 0; k < 4; k++) {
    int ni = i + di[k], nj = j + dj[k];
    if (ni >= 0 && ni < n && nj >= 0 && nj < m) {
        // (ni, nj) — сусідня клітинка, що лежить у межах поля
    }
}
```

> [!IMPORTANT]
> Перевірка `ni >= 0 && ni < n && nj >= 0 && nj < m` обов’язкова: у клітинок на краю поля частини сусідів немає. Без перевірки програма вийде за межі масиву.

Для восьми сусідів (разом із діагональними) перебирають усі зміщення від −1 до 1 по обох осях, крім (0, 0):

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<char>> g(n, vector<char>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> g[i][j];          // cin >> для char пропускає пробіли й переходи на новий рядок

    // скільки зірочок навколо клітинки (1, 1)?
    int i = 1, j = 1, stars = 0;
    for (int di = -1; di <= 1; di++)
        for (int dj = -1; dj <= 1; dj++) {
            if (di == 0 && dj == 0) continue;
            int ni = i + di, nj = j + dj;
            if (ni >= 0 && ni < n && nj >= 0 && nj < m && g[ni][nj] == '*') stars++;
        }
    cout << stars << "\n";
    return 0;
}
```

```input
3 3
*..
.*.
**.
```

```output
3
```

Клітчасті поля часто задають рядками символів: `.` — порожня клітинка, `*` чи `#` — перешкода. Таке поле зручно зберігати в `vector<vector<char>>`.

> [!TIP]
> Якщо таблиця має сталий розмір, її можна оголосити як звичайний двовимірний масив: `int a[105][105];` — поза `main`, щоб він був заповнений нулями.

## Перевір себе

```quiz
? Як звернутися до клітинки в третьому рядку і першому стовпці (якщо рахувати рядки і стовпці з одиниці)?
- `a[3][1]`
+ `a[2][0]`
- `a[1][3]`
: Індекси починаються з нуля: третій рядок — це індекс 2, перший стовпець — індекс 0.

? Які клітинки квадратної таблиці `n × n` лежать на побічній діагоналі?
- `a[i][i]`
+ `a[i][n - 1 - i]`
- `a[i][i + 1]`
: Побічна діагональ іде з правого верхнього кута в лівий нижній.

? Що станеться, якщо не перевіряти межі поля, переглядаючи сусідів клітинки на краю?
+ Програма звернеться до неіснуючих елементів масиву
- Нічого, програма автоматично пропустить таких сусідів
- Програма не скомпілюється
: Наприклад, у клітинки з `i = 0` немає сусіда зверху: `a[-1][j]` не існує.

? Скільки разів виконається внутрішнє тіло циклів для таблиці 3 × 4?
- 7
+ 12
- 4
: 3 рядки по 4 стовпці — 12 клітинок.
```

#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<vector<char>> g(n, vector<char>(m));
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> g[i][j];
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (g[i][j] == '*') {
                cout << '*';
                continue;
            }
            int count = 0;
            for (int di = -1; di <= 1; di++)
                for (int dj = -1; dj <= 1; dj++) {
                    int ni = i + di, nj = j + dj;
                    if ((di != 0 || dj != 0) && ni >= 0 && ni < n && nj >= 0 && nj < m && g[ni][nj] == '*') count++;
                }
            cout << count;
        }
        cout << "\n";
    }
    return 0;
}

## Коротко

- `vector<vector<int>> a(n, vector<int>(m));` — таблиця `n × m`; `a[i][j]` — рядок `i`, стовпець `j`.
- Таблицю обробляють двома вкладеними циклами: зовнішній — рядки, внутрішній — стовпці.
- Головна діагональ — `a[i][i]`, побічна — `a[i][n - 1 - i]`; транспонування — `b[j][i] = a[i][j]`.
- Сусідів перебирають масивами зміщень і обов’язково перевіряють межі поля.
- Клітчасте поле з символів зберігають у `vector<vector<char>>`.
